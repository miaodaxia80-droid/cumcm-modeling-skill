# 做题能力迭代（永久）

> **迭代规则就这两张表。加、减、改都在这里；禁止再把门槛/三问抄到 SKILL、AGENTS、workflow、anti-stall。**
> **2026-09-11 立。**

目的：把下次换一道同形态题还能快速闭环的做法留下。短表是索引，旧库是正文。只能增强，不封顶。
写不写论文只认 `paper-format.md`。流程节奏只听 `contest-workflow.md`。

---

## 一、干什么

| 块 | 规则 |
|----|------|
| 定位 | 表上没有照样做。现场和表打架听现场。拆题认到熟题型可先看短表当开场枪，对不上就丢表按现场做。认到题型/数据形态只加速当前题，禁止认到就把做法钉死。`*数模经验.md` / 卡点簇 = 放弃信号记录，不是这道题永不做第二条路。 |
| 落哪 | 步骤/公式/证伪/长链 → `知识库/` 已有对应模块。一行打法或指针 → `知识库/打穿短表.md`。这次正式产出（论文/代码/结果）→ 任务根对应夹。任务根**禁止**复盘.md / 经验.md（写进知识库/短表，不进任务根）。写短表或改一行指针不超过半分钟；写不成形 → 不写，继续做。 |
| 门槛 | 进的是打法，不是这道题。**过门槛** = 打开磁盘 `modeling-value.md`「完成度」那一节，拿这篇**正文里做成了啥**对照（全问闭环 + 数字可溯源 + 图真数据）；不以「感觉做得不错」为准。读磁盘 rules 现稿。一条都没中 → 这篇不进表。用户丢进对话的他人优秀论文/新打法：对话里要有能对照的实质内容（模型组合、参数处置、检验套路），只有一句「这篇拿了国一」→ 不进。 |
| 三问 | 过门槛之后才问，答不出或否定 → 不进表。① 换一道同形态题（同为 C 题数据评价类、同为 A 题机理类），还能认到 A、按 B 去打吗？② 认的是不是只有这道题特有的信号/数据形态？换到同形态认不到同一套 → 不进（单题备忘）。不是数据字段名黑名单：下次同形态还能认到同一套、差得出新认法，仍按三问进。②.1 无新认的通用枪不进：认的只是「归一化、划分训练测试、画个分布图」→ 不进（这是本分，`data-cleaning.md` 已写）。有新认（信号判别、坑位证伪、检验组合）才往下。③ 打开短表已有行：多出来的是新打法、新假点，还是同一做法的重复？差不出就不写；差得出且已有同类 → 只补原行，细节进模块。三问都过、库里没有同类、能写成「认 A → 打 B」、下次同形态题还有机会加速 → 才加新行。 |
| 太窄 | 见三问①②，不另立一档。换到同形态认不到的（这题特有字段、特有附件结构）→ 不进、不补。即使这次做成了，也只是单题备忘。①已经放过的同形态不算太窄。 |
| 两条线 | 本窗自己做出并写下的：先过门槛，过了再三问，过后直接写/补，不等「放」、不问。用户本人把优秀论文/经验丢进对话：自己先看懂。没有可对实质 → 不进。有实质则先过门槛，过了再三问。要进短表或补模块，都必须先过门槛。过了 → 直接补，回一句懂/补了或懂/不补。只对这道题成立、网上通用教科书内容重复、太窄、门槛没过 → 不补。禁止一篇论文一行往短表塞。 |
| 已有同类 | 思路已经在短表/模块里 → 禁止再开一行。同构再做一次、打法没新差分 → 不动文件（论文该写还写）。信号判别/打法/假点/检验套路有新的能下次用的（换题还能撞上，不是这道题特有）→ 只补足已有那一行或那一篇。新到已经不是同一「认 A 打 B」→ 才加新行。补的是打法差分，不是这道题、不是这份结果摘要。特有字段名、附件里的具体列名进「打哪」举例，不进「认什么」。 |
| 谁写 | 单窗：过门槛再三问，过后自己写/补。拉了子线程做题：禁止子线程直接改短表；子线程在本问 `结果/` 里写一行 `拟进：认…打…` / `拟补：哪一行多了啥` / `不进：门槛没过`，主控收回后过门槛+三问再并。spawn 交付必须含迭代。 |
| 不挡推进 | 并短表不挡做题：问 i 收口要推进就先推进，短表可稍后并。15 分钟写不成短表行 → 不写，继续下一问。无正式产出 = 无拟进。 |
| 怎么读 | 该开的模块必须开；省 token 是顺带，不是笼子。拆题：① 先读 `打穿短表.md`；② 认到、对得上 → 当开场枪，指针行必须打开对应模块看细节，禁止只靠短表半句生搬；③ 打完开场立刻回 `contest-workflow` 主路径。磁盘有 `*数模经验.md` 才和短表并行打开，没有不算缺。表是空的、对不上 → 直接按 Phase 做，不许停下来等表。打开模块 ≠ 只用表上那一招。 |
| 一行长什么样 | 认什么：题型/数据形态/问句信号，禁止写成「2023 年 B 题」。打哪：模型组合与关键处置，两句封顶，多了进模块，短表写「见 xxx.md」。出什么算成：什么结果形态算站住了（能回答「评委拿到什么」）。假点：只写「这种信号不是这个模型/这条路死在哪」。 |
| 假点 | 假点只记「这种形态/做法站不住或不是这个问题」。禁止写进假点：「这道题没做出来」「这次超时」「这道题试了不行」。这次没成 = 这道题现场不行，下一道同形态照样打。禁止因此把整行标失效。只有确认「形态从来不通 / 整个打法前提没了」才改假点或删行。拿不准就不改表，继续做。 |
| 短表肥了 | ① 并：同一「认什么」多行合成一行。② 分流：某簇不是一行能说清 → 细节并进已有模块，短表改 1 行指针；没有对应模块再新建。③ 只删：确认形态不是这问题的假点；确认打法前提没了；误写进去的教科书重复行。④ 禁止删：仍能加速闭环的打法行。冷门 ≠ 作废。大约 60 行只是提醒该做 1～2 步，不是配额。拿不准 → 留。 |
| 模块肥了 | 某篇长到翻半天 → 按打法/题型拆成两篇，短表指针改到新篇。禁止按年份拆库、短表和模块全文互相复制（细节只在一处）。 |
| 何时动文件 | 单窗：问收口后有新打法 → 过门槛+三问 → 同一轮写/补。子线程：写拟进行，主控并。用户丢来的优秀论文：看懂后有可对实质 → 过门槛+三问再并。做完一道题不另写复盘——复盘材料只在过门槛后进短表/模块。 |
| 开场怎么用 | 开场枪只打当前题。指针行必须打开对应模块。禁止认到题型就复制别的题的整篇论文结构生搬。打完开场立刻回流程。短表不是清单、不是上限。 |

## 二、不干什么

| 条 | 规则 |
|----|------|
| 不进短表 | 某题今天做完了的流水；求解器跑了几分钟；纯排配置折；只用一次的参数取值；未收口的半截模型；「这道题什么模型都没建出来」。无新认的通用枪（归一化、划分数据集、画直方图、检查缺失值）不进。进短表必须先过门槛，再过三问。不进短表 ≠ 该问不做了。 |
| 禁止 | 用「列了思路」冒充做题进度；写表超过半分钟还在磨字。短表写成日记、某题档案。教科书通用内容进表；库里已有还另开一行；有新差分却不补原行；太窄还硬补；生搬短表、表没有就不做；单题没成就把打法标死亡；为防臃肿删仍能加速的行；按年份拆一堆短表；每题通读整库。借「迭代」少做问、少检验。把迭代理解成挡推进/等并完短表才做下一问。 |
| 写不写 | 只认 `modeling-value.md` 完成度节。本表不管格式/语言/交付，只管打法沉淀。短表和模块不定级、不另建评分表。细节一长写进对应旧模块，短表只留指针。 |

---

**一句话：** 短表沉淀「认什么题型信号 → 打什么组合 → 什么算站住 → 什么死路」；门槛 = 真闭环有实据；三问 = 换同形态题还认得吗；单题特有内容只进论文不进表；写不成形不硬写，继续做题。
