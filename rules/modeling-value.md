# 得分价值导向（强制经验）

> 来源：数模竞赛评审规律复盘（摘要初筛 → 分项评审 → 四标准）。
> 职责：保证每问闭环、四件套不空窗，力气只推进真有得分的点。论文怎么写只认 `paper-format.md`。
> 主流程（Phase 0～6、一问闭环、节拍）认 `contest-workflow`；本文件管「先做哪问、力气怎么分、什么才算真得分」。

---

## 1. 得什么分：真价值优先

评委四标准（历年评审纲要有据可查）：**假设的合理性、建模的创造性、结果的正确性、表述的清晰程度**。
有价值 = 能被这四条接住的产出。力气分配只认下面 §1.1。矩阵有入口仍做或 N/A，不删项。

**「正确性」语义（易误读，务必记准）：**
- 评委要的不是「唯一正确答案」，是 **结果与题意一致、内部自洽、可复算**
- 数值有量级合理性（GDP 量级的量不能算出百万量级）；排名有可解释的区分度
- 「模型跑通了」≠「结果对」；对不上题意问法的求解白跑

### 1.1 力气怎么分（先打最容易被评委接住的）

不删项、不加第五件套、**检验与摘要同硬**。

| 先打 | 说明 |
|------|------|
| 摘要（含数字） | 评委第一关；初筛阶段摘要 = 论文。必含每问模型名 + 关键数值。写法认 `abstract-writing.md` |
| 每问闭环的真数值 | 每个小问都要「真实运行 → 结果文件 → 数字进正文」；这是「结果正确性」的实体 |
| 图表 | 第二眼即看；每问至少一张真数据图，规范认 `plot-spec.md` |
| 假设与符号 | 「假设合理性」直接对应；假设要编号、有理由、与求解一致 |
| 检验（两级） | 单问收口前最低验证立刻做；跨情景灵敏度/稳健性/基线对比 Phase 4 全文统一——省奖与国奖的常见分水岭（`result-check.md`） |
| 模型对比与创新点 | 同一问两条路对比、改进经典模型的缺陷，是「创造性」的落点；真实跑了才写 |

**没数据：** 先摸清能拿到什么 → 造假设登记 → 降级算例闭环。**有数据：** 先清洗（`data-cleaning.md`）→ 每问主模型 → 独立验证证据 → 图。

**做了不当主业：** 问题重述的华丽改写（一页封顶）、与本题无关的模型堆砌、没有数值支撑的「创新叙事」。
**清单里已经有的** 灵敏度分析 / 稳健性检验 / 方案对比：做完或写 N/A，只是不插到每问闭环前面。不是每题都找这些口；题面点名了不许装没看见。

## 2. 做到这些别停在半截（测法）

论文格式只认 `paper-format.md`。这里只说怎么继续做：

- 数据清洗出问题列 → 立刻转该列对建模的影响决策（剔除/填充/变换），不是停在「发现缺失」
- 主模型出数 → 跟独立验证证据与图，数字不进正文不算闭环（`contest-workflow` §2）
- 结果反常识（量级/方向不对）→ 查量纲、查符号、查数据方向，不是硬着头皮写进论文
- 题面问「给出你的建议/方案」→ 必须落到可操作项并给定量依据（用模型结果说话）
- 中间参数拟合出来 → 看能不能当后问输入（`contest-workflow` §4.2.2）
- **中危升链的等价物**：某问结果「出来了但单薄」（只有总数没结构、只有点估计没区间）→ 先加维（分结构/给区间/做对比）再成文，不是拿单薄结果直接成文

## 2.2 做题偏好禁令（永久）

- **禁止**只写「思路与方案」不出数——评委不读大纲
- **禁止**把精力钉在问题重述/符号表的美观上；连续多问没碰 **真实求解 / 独立验证 / 检验**
- **必须**按 §3 完成度矩阵推进：每问闭环、独立验证证据、两级检验、图、摘要数字——**各都要有**（与 `contest-workflow` §2 收口表同源）
- 任意问出数后 → **立刻**做该问最低验证（sanity 三连 + 独立验证证据 1 项）；跨情景灵敏度/稳健性归 Phase 4 全文检验（`contest-workflow` §5 两级检验），禁止出完数就堆格式
- 有多问时禁止只精做一问：完成度（全问闭环）优先于单问深度；时间富余才加深度

## 3. 测全：完成矩阵（每轮目标至少过一遍）

对当前赛题逐项勾选，**不能只精做摘要/只精做模型**。

| 项 | 探针要求（有入口就做完；无入口 N/A+原因） |
|----|----------|
| 逐问闭环 | 每个小问都有「输入→模型→输出」+ 真实数值（`contest-workflow` §2 收口表） |
| 独立验证证据 | 每问 ≥1 项（菜单：第二模型/解析特例/守恒/约束残差/基线/穷举/回测…见 `result-check.md` §三）；偏差写进正文 |
| 检验（两级） | 单问：sanity 三连 + 独立证据；全文：灵敏度（参数范围按来源定，默认 ±10% 起步）、误差指标、稳健性/基线对比汇总 |
| 图 | 每问至少一张真数据图；全文 8～15 张为宜；规范认 `plot-spec.md` |
| 假设 | 编号、有理由、与求解一致；常识假设单独标注 |
| 符号表 | 全部符号、量纲、含义，一处集中 |
| 对比/择优 | 题面若问「方案选择」→ 必须有定量对比表 |
| 摘要 | 8 要素全勾（`abstract-writing.md`）；每问有数字 |
| 参考文献 | 真实、格式统一（GB/T 7714）；不编造 |
| 附录代码 | 真实运行版；README 交代运行顺序与环境 |
| 提交包 | PDF + MD5 + 支撑材料（按当年要求） |
| 其它现场要求 | 题面/用户点名的特殊项照样做 |

## 4. 数字与证据：禁止空数

1. 每个论文数字有唯一来源：`结果/q*/summary_q*.md`（`contest-workflow` §4.3）
2. 摘要、正文、图题、表格四处数字必须同源一致
3. 结果要带不确定性的话就给区间/置信度（做了才算，没做不编）
4. **差分是硬证据**的等价物：**量级 sanity check**——结果值除以题面已知量，量级差 10 倍以上必须查一遍再进正文

**教训实例（常见翻车）：**
- 摘要写「建立了 XX 模型，取得了良好效果」零数字 → 初筛直接掉档
- 预测题没做平稳性检验直接上 ARIMA，残差爆炸 → 结果站不住
- 评价类只用 AHP 主观赋权没做一致性检验 → 「假设合理性」扣分
- 图里是手工编的数据 → 评委复算对不上，整篇信用崩

## 5. 执行节奏

1. **开局齐套**：任务夹、进度.md、拆题清单、数据摸底、路线表
2. **价值排序**：按 §1.1 力气先打 摘要/逐问真数/图/假设/检验；问题重述与符号表够用就好
3. **全问闭环 + 全项勾完**（有数据的问优先真出数）；新问入队即推进；成文先摘要
4. **只留可复核证据**（结果文件、图源、参数表）；不堆无效「收获」
5. 成文按 `paper-format.md`；单问单薄先加维再成文；草稿不替代终稿

## 6. 自检（交结论前）

- [ ] 每个小问是否都有可指认的数值结果？「方案建议」是否有定量依据？
- [ ] 独立验证证据是否 ≥1 项或 N/A + 原因？口径（official/assumption/demo）登记了吗？
- [ ] 「正确性」是否误判成「跑通了就算对」？量级 sanity check 做过没有？
- [ ] 全文检验是否真跑过（不是只写了「进行灵敏度分析」）？
- [ ] 每问是否至少一张真数据图？有无手工编数据冒充？
- [ ] 摘要是否每问有模型名 + 数字？有无零数字句？
- [ ] **本轮是否偏科只精做一问？** 是否把公式写完没跑数当「完成」？
- [ ] 中间结果有没有喂给后问？假设与求解是否一致？
- [ ] 抄到的参数是否标注了来源（题面/文献/假设）？有没有编造文献？

---

## 7. 一句话

**全问闭环 + 全项勾完；力气按 §1.1 先打 摘要/逐问真数/图/假设/两级检验；数字必须可溯源、量级必过 sanity check；中问单薄先加维；成文摘要优先。论文怎么写只认 `paper-format`。**
