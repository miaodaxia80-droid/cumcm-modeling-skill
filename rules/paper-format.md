# 论文写作格式（永久 · 唯一）

> **以后论文格式规则只改本文件。** 加、减、改都在这里；禁止写到 SKILL、AGENTS、workflow 或其它文件。
> 结构节奏认 `contest-workflow` §5；摘要写法细节认 `abstract-writing.md`；图表规范认 `plot-spec.md`。
> 当年官方格式规范若由用户提供 → 以用户版为准（当次指令压过默认）；未提供 → 按本文件。

收「怎么建模型」细节仍可查知识库对应模块；**写不写、怎么写、落哪** 以本文件为准。

---

## 一、正文怎么写（版式 + 结构）

描述用客观学术语体；「我们/本文」可用，禁止第一人称叙事腔（「我算了半天」）。无科普（不解释什么是线性规划），面向评委。全部数学量用公式/符号，不出现「大约很多」这类模糊量词替代数值。

| 块 | 规则 |
|----|------|
| 题号与标题 | 首行：题号（如「2026 年 CUMCM C 题」）；标题自拟（反映模型核心，如「基于 XX 与 XX 的 YY 模型」），一行，不浮夸。禁止出现队号以外的任何身份信息（姓名/学校/地区/指导教师——按当年匿名要求，连「我校」字样也不写） |
| 摘要页 | 第一页专用页：题号 + 摘要正文（默认 300～600 字；当年官方规范/用户要求优先）+ 关键词 3～8 个。逐问给「模型名 + 方法 + 数字结果」。零数字句 = 违规。结构模板认 `abstract-writing.md`。摘要页单独一页，不计入正文 |
| 问题重述 | 不抄题面。用 1～2 段重述背景 + 一句问题本质；可直接引出「问题分析」。半页～1 页封顶 |
| 问题分析 | 每问一小段「思路为什么这样走」+ 总体技术路线图（流程图一张）。这是评委理解全卷的地图，必须画 |
| 模型假设 | 编号列表。每条：「假设内容 + 一句理由」。题面已给的不重复设；为简化造的假设标「为简化问题」；强假设（影响结论的）要在检验部分有对应交代 |
| 符号说明 | 一张三列表：符号 / 含义 / 单位。全文符号与表一致；后文新符号出现时随文说明 |
| 模型建立与求解 | **主体，按问题分节（5.1 问题一 …）**。每问内：① 模型推导（公式编号 (1)(2)…）② 求解方法与算法（必要时给伪代码/算法框）③ 结果呈现（表 + 图，数字来自 `结果/q*/summary_q*.md`）④ 与独立验证证据的对照一句。禁止把代码清单当求解过程；禁止「解得（数字）」但数字无溯源 |
| 模型检验 | 两级检验的全文部分：灵敏度分析（参数范围按来源定：题面区间/拟合标准误/物理范围，无信息时默认 ±10% 起步，出图）、误差分析（拟合/预测误差指标）、稳健性（扰动/子样本重跑）。哪项没做就别写哪项（`result-check.md`） |
| 模型评价与推广 | 优点（2～3 条，具体）、缺点（1～2 条，诚实）、推广（该框架还能用于什么场景，一两句）。禁止「模型完美无缺点」 |
| 参考文献 | 真实文献，格式 GB/T 7714：`[1] 作者. 题名[类型]. 出处, 年, 卷(期): 页.`；**禁止编造**；正文引用处标 [1]；教材/官方文档可引。数量 5～12 条为宜 |
| 附录 | 附录 A：核心代码（真实运行版，带注释，README 说明运行顺序）；附录 B：关键数据表/补充图表（如有）。代码要能对应正文结果 |
| 排版 | 正文宋体小四、标题黑体、西文 Times New Roman、行距 1.5 倍左右——**默认样式**，当年官方规范/用户提供要求时以其为准；图表居中、编号连续（图 1/表 1）、每个图表有标题且正文引用过；公式居中右侧编号 |
| 落盘文件 | `任务根/论文/`。LaTeX 优先（`paper-template.md` 给骨架）；用户点名 Word → 按 Word 交付。CRLF 不重要，PDF 交付为准 |

### 摘要专规（简版，细则认 `abstract-writing.md`）

逐问一句「针对问题 X：建立 … 模型，采用 … 求解，得到 …（关键数字）」+ 一句检验/亮点 + 关键词。**禁止**：背景铺陈超过两句；「首先/其次/最后」流水账；只写方法名不写数字。

## 二、写不写 / 落哪

| 条 | 规则 |
|----|------|
| 不写 | 没跑数的结果数字；没做的检验结论（「模型稳定」但灵敏度没跑）；编造的文献；与本题无关的模型展示；「本文具有重大意义」类空话；代码全文（附录只放核心代码，全量代码在 `代码/`） |
| 立刻写 | 每问收口 → 该问求解正文进 `论文/草稿.md`；检验做完 → 检验节；摘要等正文成形后写并至少打磨两轮 |
| 数字同源闸 | 摘要/正文/图/表四处数字必须同源自 `结果/q*/summary_q*.md`；终检逐处核，对不上以结果文件为准改正文 |
| 匿名闸 | 交稿前全文搜索：姓名、学校、地区、「我校/我们学校/学院」；出现即删。队号按当年要求写在指定位置（不在正文出现） |
| 文献闸 | 每条文献可核（真实出版信息）；拿不准出处 → 删掉该引用，正文改为「基于 XX 模型原理（如 Logistic 增长）」表述 |
| 别重复写 | 同一结果不在问题重述、分析、求解三处重复给数值表；正文给一次，其余引用 |
| 清理 | 用户说清理：没有终稿 → 保留 `结果/` 与 `代码/` 删中间稿；有终稿 → 论文/代码/结果/提交包全留 |
| 语言 | 国赛中文；美赛 MCM/ICM 英文（结构同上，摘要在前，Competition Use 声明按当年规则）；研赛/其它赛事按其格式规范，无规范则本文件结构通用 |
