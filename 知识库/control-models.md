# 控制与序列决策（control-models）

> 对得上：最优控制、随时间做决策（每步影响后面）、跟踪/调节目标、马尔可夫决策、策略优化。
> 主线：状态方程 → 目标泛函 → 求最优控制/策略 → 闭环仿真验证。
> 与 `diff-models.md`（动力学方程）、`op-models.md`（静态优化）、`numerical-models.md`（数值积分）配合。

## 一、先判断问题形态

| 形态 | 特征 | 工具 |
|------|------|------|
| 静态优化 | 一次决策，无时间结构 | `op-models.md`（LP/MIP） |
| **离散序列决策** | 阶段推进、状态转移确定 | **动态规划**（本篇 §二） |
| **连续最优控制** | 控制量 u(t) 是时间的函数 | 本篇 §三 |
| **随机序列决策** | 转移有概率 | MDP（本篇 §四） |
| 跟踪/镇定一个目标 | 给定参考轨迹要跟随 | PID / LQR / MPC（本篇 §五） |

## 二、动态规划（确定性多阶段）

```
要素：阶段 k → 状态 s_k → 决策 a_k → 转移 s_{k+1} = f(s_k, a_k) → 阶段代价 c(s_k, a_k)
倒向递推：V_k(s) = min_a { c(s,a) + V_{k+1}(f(s,a)) }，边界 V_N(s) 已知
实现：状态离散化网格（维度灾：状态 ≤3~4 维才直接 DP）+ 回溯记录最优策略
检验：状态网格加密一倍，策略/值函数变化 < 容差（`numerical-models.md` §一收敛纪律）
```

**适用信号**：题面有「每阶段/每年/每步……且当前决策影响后续」——背包多期、库存多周期、设备更换、路径依赖调度。

## 三、连续最优控制

| 方法 | 适用 | 落地 |
|------|------|------|
| 变分法/庞特里亚金最大值原理 | 解析路线，低维 | 写 Hamiltonian → 协态方程 → 最优性条件；能推出 bang-bang 结构最好 |
| 直接法（推荐） | 通用 | 控制量离散化 → 整段变成大规模 NLP：`scipy.optimize.minimize` 带constraints，或 `casadi`；Solve 后画状态/控制轨迹 |
| 验证 | 必须 | ① 最优轨迹代回状态方程残差 ② 换离散格点数重解，目标值收敛 ③ 与启发式/直觉策略对比（恒定控制、线性反馈），最优目标必须不劣于它们 |

## 四、马尔可夫决策过程（随机转移）

```
五元组 (S, A, P, R, γ)：状态集、动作集、转移概率 P(s'|s,a)、奖励 R、折扣 γ
求解：值迭代 / 策略迭代（收敛判据：值函数变化 < ε）
转移概率从哪来：数据估计（计数归一）+ 平滑；样本少时敏感性交代（γ、P 扰动）
```

**纪律**：P 和 R 是假设还是估计要分开交代；MDP 结果的置信度受 P 估计质量限制（`uncertainty-and-identifiability.md`）。

## 五、反馈控制三件套（跟踪/调节题）

| 方法 | 一句话 | 用法 |
|------|--------|------|
| PID | 误差的比例-积分-微分反馈 | 参数整定：先 P 后 I 再 D；给阶跃响应曲线（超调/调节时间/稳态误差） |
| LQR | 线性系统 + 二次代价最优反馈 u = −Kx | `scipy`/`python-control`；Q、R 权重敏感性交代 |
| MPC | 每步滚动优化预测时域 | 预测模型 + 时域 N + 约束处理；滚动仿真展示跟踪与约束满足 |

**验证**：闭环仿真（含扰动/噪声注入）→ 跟踪误差指标（IAE/RMSE）+ 控制量是否越界 + 与开环/无控制对照。

## 六、常见坑（假点）

- 状态空间漏维（漏掉影响未来的状态变量）→ 「最优策略」基于错误信息集
- DP 状态网格太粗 → 策略是网格伪影；加密验证没做
- MDP 转移概率拍脑袋 → 结果可信度无从谈起；要么数据估计要么敏感性扫描
- 最优控制解不代回状态方程验残差 → 轨迹本身不满足动力学
- 只报开环最优轨迹、不仿真闭环抗扰 → 控制题的核心（鲁棒性）没答
- PID 只给参数不给整定过程和响应指标

## 七、论文里写什么

1. 系统建模：状态变量表（含量纲）、状态方程、约束、控制/决策变量
2. 目标泛函/奖励函数（每项含义 + 权重来源）
3. 求解方法（DP 递推式 / 直接法离散化 / 值迭代收敛曲线）
4. **最优策略/轨迹图 + 闭环仿真对比图**（最优 vs 基线策略）
5. 验证：网格收敛、残差、扰动仿真、参数（γ/Q,R/N）敏感性

**一句话：** 先分清序列/控制/随机三形态；DP 必做网格收敛、最优控制必验动力学残差、MDP 转移概率要有来源、控制题必须闭环仿真对照基线策略。
