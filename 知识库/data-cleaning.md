# 数据清洗与特征（data-cleaning）

> 进问先摸数据；本篇管「原始附件 → 可建模数据」。与 `SKILL.md`、`rules/contest-workflow.md` Phase 3 配合。
> 清洗动作必须可复现：清洗脚本进 `代码/`，清洗后数据进 `数据/`，变换规则进 `进度.md`。

## 一、开场三连（任何数据题第一步）

```
1. 读取并登记数据字典：逐列 → 类型（数值/类别/时间/文本/ID）+ 含义推断 + 样值
2. 质量三连：缺失率表、异常值（IQR/3σ）、重复行与重复键
3. 分布速览：数值列直方图/箱线图、类别列频数表、时间列范围检查
   → 出 1~2 张探查图（进结果/，论文「数据预处理」节可直接引用）
```

**禁止**：不读数据就选模型；清洗动作不记录；原始附件被改写（原件在 `题目/` 只读）。

## 二、缺失值（先判机制，再定处置）

**主规则 = 缺失机制 + 下游敏感性**，缺失率只是参考信息：

```
1. 判机制：MCAR（完全随机）/ MAR（依赖其它变量）/ MNAR（依赖自身或目标变量）
   探判：缺失 vs 非缺失样本在其它变量上有没有系统差异（分组对比）；缺失比例随时间/类别漂移吗
2. 定处置：机制 + 该列对建模的作用（自变量/目标变量）+ 下游模型对缺失的敏感度
3. 留痕：处置决定 + 理由进 进度.md；正文预处理节一句话交代
```

| 缺失率（无机制信息时的默认提示） | 默认处置（可被机制判断推翻） |
|--------|------|
| < 5% 且样本多 | 直接删该行（记录行数） |
| 5%~30% | 数值列：均值/中位数/插值（时间序列用时间插值）；类别列：众数或「未知」类 |
| > 30% | 该列降权/剔除，或缺失指示器（missing indicator）当特征；决策写进假设 |
| 缺失本身有含义（问卷未答、设备未上报） | 保留「缺失」当独立类别，不做填充——**缺失是信息** |

**机制特例：**

| 场景 | 处置 |
|------|------|
| MNAR（缺失与目标相关，如高收入拒答） | 删除/均值填充都会带偏 → 缺失指示器当特征 + 「含/不含该列」敏感性对比；正文如实交代 |
| 时间序列缺口 | 看缺口长度与位置：短缺口插值，长缺口不硬插；缺口跨越结构变化点 → 分段处理 |
| 交叉验证/回测中的填补 | 填补统计量只能在训练折内算，**禁止**用全量统计量填训练+测试（信息泄漏） |
| 机制复杂、样本可估 | 多重插补（MICE 类），传播缺失不确定性，正文报告插补间方差 |

**禁止**：无脑 dropna 把样本砍半；用「0」填充有量纲的数值列；把缺失率阈值当自动决策不判机制。

## 三、异常值

```
先判：异常 = 错误数据（录入错）还是真实极端值（有大含义）？
  错误数据 → 修正（用上下文/规则）或剔除，记录
  真实极端值 → 保留 + 做一次「含/不含极端值」的对比，正文交代稳健性
探测工具：箱线图、IQR（Q1-1.5IQR, Q3+1.5IQR）、z 分数、孤立森林（大样本）
```

## 四、口径与量纲闸（最易翻车）

| 问题 | 处置 |
|------|------|
| 单位混用（万元 vs 元、% vs 小数） | 统一量纲并记录；目标函数两侧单位必须一致 |
| 编码不一致（“男/女” vs 0/1；省名全称/简称） | 建映射表，一次性归一 |
| 时间格式混杂 | 统一为 datetime；时区/日期边界检查 |
| 多表关联键 | 先验证键唯一性再 merge；merge 后行数对不上要查明 |
| 指标方向（效益型越大越好 / 成本型越小越好） | 评价/综合类必须先正向化：成本型取负或倒数；记录在案 |

**官方 Excel 附件三闸（2024C 实测，全部通用）**：

| 坑 | 处置 |
|----|------|
| **合并单元格**：地块名/作物编号等键列是 Excel 合并单元格，只有块首行有值 | 对键列 `ffill()` 后再过滤；**纯 dropna 会静默丢掉整块数据**（实测 87 条记录被砍到 54 条） |
| **类型/名称值带尾随空格**（如 `'普通大棚 '`） | 所有字符串列全局 `str.strip()`；否则 merge/groupby 静默分裂成两个键 |
| **字段名冲突**（地块面积与种植面积同叫「面积/亩」） | merge 前检测同名列并改名（如 plant_area）；merge 后 KeyError 多为列名冲突 |
| 表尾注释行（「注：」「(1) 该数据是…」） | `pd.to_numeric(col, errors="coerce")` 过滤，禁止裸 astype |

**量级 sanity check**：清洗后关键量与题面/常识对照（人数应 < 千万级；金额与题面给的预算同量级），差 10 倍以上必须查。

## 四b、题面参数闸（附件没直接给的量）

| 缺的量 | 处置 |
|--------|------|
| 价格给区间不给定值（如 `2.50-4.00`） | 取区间中点为基准价；登记为假设并做价格 ±扰动灵敏度 |
| 预期销售量无直接字段 | 用 2023 年该作物当季总产量代理（2023 视为市场出清）；登记假设 |
| 官方附件不齐/不在手 | 见 `rules/contest-workflow.md` §1.0a 数据获取闸：官网赛题页 zip 为原始出处，二手来源必须核对 |

## 五、特征构造（喂模型的原料）

| 手法 | 用法 |
|------|------|
| 时间派生 | 年/月/星期/节假日标记、滚动均值（7/30 期）、同比环比 |
| 比率/差分 | 增长率、占比、人均量（总量/人口） |
| 交互 | 两特征乘积/比值（有业务含义才加） |
| 分箱 | 连续值离散化（等频/等宽/自定义区间），用于评价打分 |
| 独热/标签编码 | 类别变量；树模型可留标签编码，线性模型用独热 |
| 降维 | 高维强共线 → PCA（先标准化）；保留解释方差 ≥85% 或按题面维数 |
| 标准化 | 距离类/优化类/神经网络模型必须标准化（z-score 或 min-max）；树模型可不做 |

**禁止**：把 ID 列当特征； leakage（用了未来信息预测过去）。

## 六、数据子集与抽样

- 全量 < 10 万行 → 全量直接算，不抽样
- 百万行级 → 探查用随机抽样（固定种子），建模全量或分块；记录种子
- 分组不均衡 → 分层抽样；正文交代抽样方案

## 七、落盘规范

```
数据/clean_{用途}.csv      ← 清洗后数据
代码/clean_*.py            ← 全流程脚本（读原始→清洗→写 clean_*.csv 一键复跑）
进度.md 数据摸底节         ← 字典 + 缺失/异常处置 + 变换规则登记
结果/eda/fig_*.png         ← 探查图
```

论文「数据预处理」节写什么：数据来源与规模一句话、清洗三步（缺失/异常/口径）各一句 + 探查图引用。**不写**清洗代码细节。
