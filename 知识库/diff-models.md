# 微分方程与动力系统（diff-models）

> 对得上：增长/衰减、传染、人口、捕食、扩散、冷却、药代、任何「变化率」语言。
> 主线：机理列方程 → 平衡点稳定性 → 参数拟合 → 数值解 → 预测。

## 一、建模套路

```
1. 找状态变量（人口 P、感染者 I、温度 T、药物浓度 C…）
2. 用守恒/机理定律列 dX/dt = f(X, 参数)（增长= births - deaths；传染= β·S·I/N；冷却= k(T-T0)）
3. 参数：题面给的直接用；没给的 → 用真实数据最小二乘拟合反演（curve_fit），并报拟合优度 R²
4. 平衡点：f(X*)=0 → 雅可比特征值判稳定性（负=稳定）
5. 数值解：scipy.integrate.solve_ivp，画时序曲线
6. 灵敏度：对关键参数（β、r）按来源范围扰动看峰值/平衡态变化（范围纪律认 `result-check.md` §二）
```

## 二、经典方程库（对得上直接用）

| 场景 | 模型 |
|------|------|
| 人口/种群增长 | Malthus dP=rP（短期）；Logistic dP=rP(1-P/K)（长期） |
| 年龄结构人口 | Leslie 矩阵 |
| 传染病 | SIR / SEIR / SIS；基本再生数 R0 = β/γ（>1 流行）；可加疫苗接种/隔离项 |
| 捕食-被捕食 | Lotka-Volterra（周期解） |
| 代谢/剂量 | Michaelis-Menten；药代一室/二室模型 |
| 传热/冷却 | Newton 冷却 dT/dt=-k(T-T0) |
| 扩散/交通 | 偏微分方程（热传导/交通流 LWR），竞赛常用简化 ODE |
| 经济增长 | 索洛模型、Logistic 产出 |
| 振动 | 二阶线性方程（弹簧/RLC） |
| 战争/竞争 | Lanchester、Lotka-Volterra 竞争型 |

## 三、差分方程变体（离散时间）

dX/dt 不好解析 → 差分递推 X_{t+1} = X_t + f(X_t)·Δt（欧拉离散）；年代差分、增长阶梯问题常用；混沌敏感问题（迭代映射）给分岔图。

## 四、参数拟合反演（有数据必做）

```python
from scipy.optimize import curve_fit
from scipy.integrate import solve_ivp
def rhs(t, x, beta, gamma): ...
sol = solve_ivp(rhs, [0, T], x0, args=(beta, gamma), t_eval=ts)
# 反演：定义残差 = 模型曲线 - 观测；curve_fit 或 lsq 拟合 (beta, gamma)
```

- 拟合结果报：参数值 ± 标准误、R²
- 拟合不收敛 → 给参数取值范围加 bounds、换初值多起点、或归一化量纲

## 五、稳定性与定性分析（评委看重）

- 平衡点求解 + 雅可比矩阵特征值 → 结论（稳定/不稳定/鞍点）
- 相图（二维系统画 phase portrait / 轨迹）
- 阈值条件（如 SIR 的 R0<1 疾病消退）→ 有控制含义的结论（这往往是「创造性」得分点：把模型变成「策略比较」）

## 六、常见坑（假点）

- 只有解析式没有数值解和曲线图
- 参数全部拍脑袋、不标注来源（题面/文献/拟合）
- 单位量纲不检查（β 的单位要匹配）
- 数值解步长太粗导致发散（ stiff 系统换 implicit 方法）
- 把「模型稳定」说出口但没做扰动分析
- SIR 忘了 N 随时间变化（出生/死亡）当长期预测用

## 七、论文里写什么

1. 机理假设一段（为什么这个方程结构）
2. 方程组（编号公式）+ 参数表（来源列：题面/文献/拟合）
3. 稳定性结论（平衡点 + 特征值）
4. **拟合曲线图（真实数据点 + 模型曲线）+ R²**
5. 情景预测图（不同参数/策略下的曲线族）

**一句话：** 机理列方程、参数必溯源、有数据必拟合、平衡点判稳定、数值解出图、策略比较出亮点。
