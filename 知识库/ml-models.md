# 机器学习与数据挖掘（ml-models）

> 对得上：大样本、带标签分类/回归、模式识别、图像/文本量化后的建模。
> 主线：基线先行 → 交叉验证 → 单模型调优 → 集成对比 → 可解释。

## 一、纪律总闸（评委最看重的三条）

1. **基线先行**：先用最笨的模型（逻辑回归/线性回归/均值）打基线；复杂模型必须显著优于基线，差值才是「模型价值」
2. **交叉验证**：k=5 折 CV 报均值±标准差；**禁止**只报一次单划分的成绩
3. **测试集隔离**：调参只用训练集 CV；测试集只碰一次（最终成绩），**禁止**拿测试集反复调参（数据泄漏）

## 二、流程模板

```
EDA（data-cleaning）→ 特征工程 → 训练/测试划分（分层/按时间）
→ 基线模型（Dummy/线性）→ 候选模型（RF / XGBoost / SVM / LR）
→ 网格或贝叶斯调参（只动 2~3 个关键超参）
→ CV 对比表 → 最优模型 → 测试集最终成绩 → 特征重要性/SHAP
```

## 三、模型选型速查

| 任务 | 首选 | 对照 |
|------|------|------|
| 表格分类（中小样本） | 随机森林 / XGBoost | 逻辑回归基线 |
| 表格回归 | XGBoost / RF | OLS/岭回归 |
| 大样本线性可分 | 逻辑回归（正则化） | SVM |
| 文本（已向量化） | TF-IDF + 线性分类 | 词频 + 朴素贝叶斯 |
| 序列 | 特征派生 + XGBoost（竞赛常用） | ARIMA（`predict-models.md`） |
| 聚类分群 | K-means / 层次 | 见 `stat-models.md` |

## 四、指标

| 任务 | 指标 |
|------|------|
| 分类（均衡） | 准确率、F1 |
| 分类（不均衡） | **AUC、PR 曲线、召回率/精确率**（不均衡时准确率会说谎） |
| 回归 | RMSE、MAE、R² |
| 聚类 | 轮廓系数、手肘 SSE |

混淆矩阵必出；不均衡数据给类别权重（class_weight）或重采样，并在正文交代。

## 五、调参最小集（够用不烧机）

| 模型 | 关键超参 |
|------|----------|
| XGBoost | n_estimators(100~500)、max_depth(3~8)、learning_rate(0.01~0.3)、subsample/colsample(0.6~1) |
| 随机森林 | n_estimators(100~500)、max_depth(5~20)、max_features |
| SVM | C、kernel、gamma |

网格 2~3 个参数 × 3~4 档即可；跑不完就贝叶斯/随机搜索（optuna 或 random_search），给出 CV 收敛证据。

## 六、可解释性（评委加分点）

- 特征重要性条形图（sklearn/xgboost 内置）
- SHAP summary（样本多时抽样画）
- 部分依赖图（PDP）看单特征影响方向
- 正文一句话解释「哪些因素驱动结果、与业务直觉是否一致」

## 七、常见坑（假点）

- 拿测试集调参/早停 → 成绩虚高
- 随机划分时序数据 → 泄漏未来
- 不均衡数据只报准确率（全猜多数类=99%）
- 只报一次划分的成绩
- 特征重要性当成因果解释（树重要性 ≠ 因果）
- 没有 naive 基线，无法证明模型增益

## 八、论文里写什么

1. 建模思路一段（为什么选这类模型）
2. 数据划分与验证方案一句（「5 折分层交叉验证」）
3. **模型对比表**（基线 vs 候选 vs 最优：CV 均值±std + 测试集成绩）
4. 特征重要性图 + 一句业务解释
5. 混淆矩阵/AUC 曲线图

**一句话：** 基线先行、CV 报均值、测试集只碰一次、不均衡看 AUC、重要性图配业务解释。
