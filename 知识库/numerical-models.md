# 数值建模链（numerical-models）

> 对得上：A 题机理题的数值落地——方程组、数值积分、PDE、逆问题、参数校准。
> 物理机理（`phys-geo-models.md`）+ 微分方程（`diff-models.md`）给出方程之后，**算得对、算得准**靠本篇。
> 主线：方程 → 无量纲化 → 离散化 → 收敛验证 → 校准/反演 → 误差交代。

## 一、数值解的验收纪律（先立规矩）

1. **网格/步长收敛必须验证**：解算一次不算完成——网格减半重解，解变化 < 容差才收口；有理论收敛阶（如差分一阶/二阶）时对照实测收敛阶
2. **守恒检查**：质量/能量/动量守恒的题，数值解的守恒量漂移要报告（封闭系统质量漂移应 ≈ 机器精度~离散误差级）
3. **数值误差 ≠ 模型误差**：网格加密后不变的是模型误差（假设带来）；加密还在变的是数值误差——两者分开交代，禁止混说
4. **量纲一致性**：方程各项单位必须一致；先无量纲化再算最稳（§四）

## 二、方程组与积分

| 任务 | 工具 | 要点 |
|------|------|------|
| 非线性方程组 | `scipy.optimize.root` / `fsolve` | 多起点防伪根；解代回方程验残差 |
| 数值积分（定积分） | `scipy.integrate.quad` | 奇点/振荡区间分段；quad 收敛警告要处理 |
| 常微分方程（ODE） | `solve_ivp` | 见 `diff-models.md`；刚性系统 `method="Radau"/"BDF"` |
| 高维/大规模 | 向量化、稀疏矩阵 | `scipy.sparse` 解大型线性系统 |

## 三、PDE 基础路线（热/扩散/波/对流）

| 方程 | 典型离散 | 稳定性 |
|------|----------|--------|
| 热方程 u_t = αu_xx | 显式 FTCS | 步长受 α·Δt/Δx² ≤ 1/2 限制，超了直接爆；稳一点用隐式（Crank–Nicolson，二阶精度无条件稳定） |
| 对流方程 u_t + c·u_x = 0 | 迎风格式 | 中心差分会振荡；CFL 条件 c·Δt/Δx ≤ 1 |
| 波方程 | 显式蛙跳 | CFL 条件 |
| 一般建议 | 先 1D 写对再升 2D；可视化每一步中间场 | `matplotlib` 热图/动画帧检查物理合理性（对称性、边界行为） |

**边界/初值条件登记（PDE 题最容易写错）**：每一类边界（Dirichlet 定值 / Neumann 定梯度 / Robin 混合 / 周期）逐条列出来源（题面给的还是假设的）；初值与题面/数据对照。

## 四、无量纲化（量纲混乱的解药）

```
选特征尺度 L、T（题面几何/时间尺度）→ 无量纲变量 x* = x/L, t* = t/T
→ 方程自动出现无量纲数（Reynolds、Damköhler 等）→ 它们就是关键相似参数
好处：① 量纲自动一致 ② 参数减少、灵敏度分析对象明确 ③ 与文献值可比
```

## 五、逆问题与参数校准（从数据反推参数）

| 场景 | 工具 | 纪律 |
|------|------|------|
| 参数少（≤5）、模型光滑 | `curve_fit` / `least_squares` | 给 bounds + 多起点；报告参数 CI（`uncertainty-and-identifiability.md` §二） |
| 噪声大/离群点 | `least_squares(loss="soft_l1")` 鲁棒损失 | 对比普通最小二乘，差异大说明有离群影响 |
| 病态（参数微变解大变） | **正则化**：Tikhonov（L2）/ L1 | 正则系数用 L-curve 或交叉验证选；正文交代正则项含义 |
| 参数可识别性存疑 | profile likelihood / 多起点重拟 | 可识别性诊断认 `uncertainty-and-identifiability.md` §五 |

**校准验收**：① 校准集拟合好 ② 留出集/另一工况验证预测（防只记住数据）③ 参数值物理合理（负扩散系数 = 有 bug）

## 六、稳态与瞬态

| 问题形态 | 做法 |
|----------|------|
| 稳态（不再随时间变） | 解代数方程组 `root`；或瞬态积分跑到不变（用时 longer）|
| 瞬态（演化过程） | `solve_ivp` 全程积分；warm-up 段分离；关注达到稳态时间 |
| 题面问「多久达到稳态」 | 定量判据（变化率 < ε）+ 判据敏感度交代 |

## 七、常见坑（假点）

- 显式差分步长超稳定性上限 → 解爆炸或出现负浓度等非物理值（先查 CFL/扩散数）
- 网格无关性没验证 → 结果是网格伪影，评委一问就穿
- 逆问题不做正则化/不报参数 CI → 病态拟合的参数毫无意义
- 校准集和验证集不分开 → 过拟合冒充好模型
- 无量纲数乱选特征尺度 → 无量纲化无意义
- 边界条件类型写错（该 Neumann 写成 Dirichlet）→ 解形状整体错
- 把数值误差的消除说成「模型验证通过」

## 八、论文里写什么

1. 方程组 + 边界/初值条件表（每条标来源：题面/文献/假设）
2. 数值方法一段（离散格式、步长/网格、求解器）
3. **网格/步长收敛表或图**（加密前后解对比 + 收敛阶）
4. 参数校准表（估计值 ± CI）+ 校准/验证拟合图（`diff-models.md` 联动）
5. 守恒量漂移一句（如适用）

**一句话：** 先无量纲化、显式格式先查稳定性、网格收敛才算解、校准必留验证集、参数必带 CI、数值误差和模型误差分开交代。
