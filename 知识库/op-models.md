# 优化建模（op-models）

> 对得上：最大利润/最小成本/最优分配/排班/调度/选址/组合优化。
> 三步走：决策变量 → 目标 → 约束；先写标准形，再编码求解。与 `solver-toolkit.md` 配合。

## 一、建模标准形（先纸上后代码）

```
决策变量：x_j = ？（连续/整数/0-1），单位、含义、个数
目标函数：min 或 max f(x)   —— 一个目标；多目标见 §五
约束：    g_i(x) ≤/=/≥ b_i —— 题面明示 + 常识隐含（非负、整数、上下限、互斥、总产能）
数据：    系数矩阵/参数表（从附件算出，程序生成，禁止手抄）
```

**常识约束清单（最易漏）：** 非负性、整数性（人数/车数/台数）、总量守恒、互斥（同一时段不重叠）、逻辑（选了 A 才能选 B 用 0-1 变量连乘）、边界（产量 ≤ 产能）。

## 二、模型选型

| 特征 | 模型 | 求解 |
|------|------|------|
| 线性目标 + 线性约束 + 连续变量 | LP | scipy.optimize.linprog / pulp |
| 需要整数/0-1 变量 | MILP | pulp(CBC) / gurobipy |
| 目标或约束非线性 | NLP / 凸优化 | scipy.optimize.minimize |
| 路径/流结构 | 图模型（`graph-models.md`） | networkx |
| 规模巨大或目标难写闭式 | 启发式 | 遗传/模拟退火/贪心 |
| 多个目标 | 多目标 | §六 |
| 阶段决策 + 后效性 | 动态规划 | 自写 DP |
| 参数不确定 / 情景 / 概率约束 | 鲁棒/随机/机会约束 | §六b |
| 每步决策影响后续 | 控制与序列决策 | `control-models.md` |

**组合拳模板（C 题常用）：** 预测/拟合先行（得需求/参数）→ 把预测值当输入系数进优化模型 → 输出方案 → 灵敏度（改预测值看方案变化）。

## 三、求解实现（pulp 最短模板）

```python
import pulp
prob = pulp.LpProblem("plan", pulp.LpMaximize)
x = pulp.LpVariable.dicts("x", range(n), lowBound=0, cat="Integer")
prob += pulp.lpSum(profit[i]*x[i] for i in range(n))          # 目标
prob += pulp.lpSum(w[i]*x[i] for i in range(n)) <= CAP        # 约束
prob.solve(pulp.PULP_CBC_CMD(msg=0))
print(pulp.LpStatus[prob.status])   # 必须确认 'Optimal' 才能写"最优"
print(pulp.value(prob.objective))
```

- **状态闸**：`LpStatus == 'Optimal'` 才写「求得最优解」；'Not Solved/Infeasible' → 查约束冲突（通常约束打架或数据量纲）
- 解丢进 `结果/q*/result_q*.csv`：决策方案表 + 目标值

### 3.1 「销量上限 + 超额折价」收入线性化（种策略类题通用，2024C 实测）

收入形如 `P·min(Q, D) + 折价·P·(Q−D)+` 时，**不要**写 min/max 进目标。设超额变量 `z ≥ 0, z ≥ Q − D`，目标里写 `P·Q − k·P·z`（k=1 滞销全损、k=0.5 半价）：目标系数为负会自动把 z 压到 `max(0, Q−D)`，收入恒等于正确分段值，模型保持线性。

### 3.2 需求上限的聚合口径（结果核算必须与模型同口径）

`min(Q, D)` 施加在 **(作物, 季, 年) 聚合产量**上（题面语义「某种作物每季的总产量超过相应的预期销售量」），**不是**逐地块项分别 min——逐地块 min 会把同一作物的超额在多个地块上重复按全价计，重算利润虚高（2024C 实测虚高 670 万元）。独立核算函数必须先聚合产量再套上限。

### 3.3 「重茬」的季数差异（按题面逐条回读，禁止套用别的年份经验）

| 地块季数 | 相邻 = |
|----------|--------|
| 双季地块（大棚/水浇地两季） | 同年 1→2 季 + 跨年 2→1 季 |
| **单季地块（露地）** | **相邻两年同作物即重茬**（x[y]+x[y+1]≤f_l）——2024C 实测漏掉会导致方案年际连作 |
| 跨年初始 | 2023 实际种植的作物对 2024 第一季的重茬约束必须编码 |

### 3.4 放宽约束单调性检查（硬）

对同结构模型做约束放宽/收紧对比时：**放宽后的最优值不可能低于收紧前**。若出现"放宽反而更差"，是求解未收敛的伪影（2024C 实测：放宽变体 120s 未收敛报 Optimal，利润虚低 12%；TL=240 重跑后恢复单调 +2.3%）→ 该结果禁止进任何表格，提高时限或缩规模重解。

## 四、启发式（模型太复杂/规模太大时）

| 方法 | 适用 | 要点 |
|------|------|------|
| 贪心 + 局部交换 | 快速基线 | 结果当 MILP 的对照下界/上界 |
| 遗传算法（GA） | 解空间巨大、目标黑箱 | 种群 50~200、交叉/变异率 0.6~0.9/0.01~0.1、保留精英；给出**收敛曲线**（迭代 vs 最优值）证明停机合理 |
| 模拟退火（SA） | 易困局部最优 | 初温/降温率 0.95~0.99；同样给收敛曲线 |
| 粒子群（PSO） | 连续优化 | 惯性权重递减 |

**启发式的论文写法**：流程图 + 参数表 + 收敛曲线 + 「与贪心/精确解对照」（小规模上 MILP 对照启发式，证明启发式可信）。

## 五、动态规划

阶段 → 状态 → 决策 → 转移 → 边界；离散背包/资源分配/路径型问题用。
实现要点：状态数控制（别爆内存）、滚动数组、回溯记决策。多阶段决策题（每步有先后依赖）优先想 DP 而不是 MIP。

## 六、多目标

| 方法 | 做法 |
|------|------|
| 加权法 | f = w1*f1 + w2*f2；**必须**给多组权重的解做敏感性 |
| ε-约束 | 主目标优化，其余目标转约束 |
| 帕累托/NSGA-II | 出**帕累托前沿图**，正文推荐一个折中方案并说明理由 |

**禁止**：只给一组权重的解就称「最优」；权重没有依据。

## 六b、不确定与高级结构（题面带波动/风险时）

| 结构 | 什么时候用 | 落地 |
|------|------|------|
| **软约束** | 允许少量违反但要罚 | 加松弛变量 s ≥ 0 进目标乘大罚系数 M；违反量进结果表交代 |
| **鲁棒优化** | 参数不确定、要最坏情况保障 | 不确定参数进盒式集（±Δ）→ max-min 形式线性化（约束对最坏取值成立）；解偏保守要交代 |
| **随机规划（两阶段）** | 情景及概率已知 | 第一阶段「here-and-now」决策 + 第二阶段情景补偿变量；SAA 用 N 个情景样本平均 |
| **机会约束** | 约束以概率成立（P(g(x)≤0) ≥ 0.95） | 正态假设下解析等价转换（均值 − z·σ 形式）；分布复杂用 SAA/仿真校验真实满足率 |
| **rolling horizon** | 多期滚动、滚动中可修正 | 每期只解当前窗口，滚动推进；期末评价全期指标 |
| **仿真优化** | 目标值只能仿真评估 | 外层优化器（optuna/贝叶斯优化/GA）套蒙特卡洛评估；每次评估种子可控 |

**共同纪律**：不确定集/情景/概率是假设还是数据估计，分列注明；机会约束的真实满足率用仿真验证过再写进结论。

## 六c、解的验收（求解器级证据）

保存并抽查以下证据（清单细则认 `solver-toolkit.md` §三b）：目标值独立重算一致、约束逐条残差 ≤ 容差、MIP 报 gap 与 bound、不可行时定位冲突约束（逐条注释或 IIS）、凸问题抽查 KKT/对偶（影子价格解释合理）。「Optimal 状态」只是及格线，不是验收。

## 七、求解失败处置（硬）

| 症状 | 处置顺序 |
|------|----------|
| Infeasible | 查约束冲突：总量 < 需求？上下限打架？逐条注释定位冲突约束（商用/开源求解器支持 IIS 直接给冲突集）；真缺资源 → 软约束+罚项（§六b） |
| Unbounded | 目标方向写反 / 漏约束 |
| 跑不完（分支定界爆炸） | ① 缩小规模试小算例 ② 加时间限制（求解器 timeLimit）输出次优解并标注 gap ③ 换启发式 |
| 解明显不合理 | 量纲检查 → 约束抄写检查 → 目标系数符号检查 |
| scipy 非凸报错 | 换凸化（取对数/变量替换）或换差分进化 `differential_evolution` |
| timeLimit 到点报 Optimal | 警惕假收敛（实测：120s 报 Optimal 利润虚低 12%，TL=240 恢复）；对账 §3.4 单调性 + 看 gap，gap 大就不是真最优 |

## 八、论文里写什么

1. 标准形（变量/目标/约束编号公式）
2. 数据来源一句（「系数由附件 X 计算得到」）
3. 求解器与状态（「经 CBC 求解，得最优值 1284.6，方案见表 X」）
4. 方案表 + 关键图（方案结构图/甘特图/路线图）
5. 灵敏度（对关键系数扰动，`result-check.md`）

**一句话：** 标准形先行、常识约束别漏、系数程序生成、Optimal 状态 + 求解器级证据才收口；不确定/风险题走 §六b、验证走 §六c；大模型启发式 + 收敛曲线，多目标给帕累托。
