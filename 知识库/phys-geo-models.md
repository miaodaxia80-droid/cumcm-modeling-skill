# 物理 / 几何 / 概率经典建模（phys-geo-models）

> 对得上：受力/运动、几何构型、光学、测量、切割下料、概率游戏。A 题常见底座，B 题常出现。
> 主线：物理定律/几何关系列方程 → 量纲自查 → 数值/解析解 → 对照题给条件。

## 一、建模套路

```
1. 把场景翻译成物理量（质量/力/速度/角度/面积）并统一单位制
2. 列关系：牛顿定律/能量守恒/动量守恒/几何约束/概率法则
3. 无量纲化（比值变量）减少参数个数，便于讨论
4. 解析解优先；解不动 → 数值解（solve_ivp / 迭代）
5. 对照题给的实测点/照片/参数 → 校准参数 → 预测
```

## 二、经典武器库

| 场景 | 模型/公式 |
|------|-----------|
| 抛体/飞行轨迹 | 运动学 + 空气阻力（F=½ρC_d Av²）→ 数值积分 |
| 弹性/绳索 | 胡克定律 F=kx；悬链线 y=c·cosh(x/c) |
| 摩擦/滚动 | 静/动摩擦、纯滚动条件 |
| 电路 | 基尔霍夫定律列线性方程组 |
| 光路/反射 | 几何光学折射反射（Snell）、镜面反射迭代 |
| 桥/结构 | 静力平衡 ΣF=0 ΣM=0；桁架内力线性方程组 |
| 测量/定位 | 最小二乘定位（TDOA/测距）、三角测量 |
| 降落伞/减速 | 阻力平衡终速 vt=√(2mg/ρC_dA) |
| 圆锥曲线/最包络 | 几何解析 + 参数优化 |
| 切割/排样/下料 | 二维排样：栅栏法/启发式装箱；小规模 MIP |
| 频率/波 | 振动模态、傅里叶分解 |
| 概率场景 | 几何概型、条件概率、贝叶斯更新、随机游走 |

## 三、量纲与合理性闸（必做）

| 检查 | 要点 |
|------|------|
| 单位一致性 | 方程两侧同量纲（重力 9.8 m/s²；密度 kg/m³）；软件里统一 SI |
| 数量级 sanity | 终速/应力/时间与常识对照（人跑速 <15 m/s；跨江桥长 km 级） |
| 极限行为 | 参数→0/∞ 时结果退化为合理极限（阻力→0 应退化为抛体） |
| 量纲分析 | 变量多时用 Buckingham Π 定理降维，展示专业度 |

## 四、数值求解与拟合

- ODE：solve_ivp（注意刚性系统换 Radau/BDF）
- 常见非线性（超越方程）：scipy.optimize.fsolve/brentq
- 参数未知 → 最小二乘拟合（curve_fit）+ R² + 残差图
- 多解/多稳定态 → 初值扫描（不同初值试出所有解）

## 五、常见坑（假点）

- 单位没统一（英里 vs 千米、克 vs 千克）→ 结果错一个量级
- 只写公式不代入数据算出数
- 空气阻力忽略与否没交代（长距离/高速必须考虑）
- 几何约束漏掉（相切/不相交/边界）
- 拍参数不标注来源

## 六、论文里写什么

1. 场景假设一段（忽略什么、为什么可以忽略）
2. 方程推导（编号公式）+ 参数表（含来源）
3. 数值/解析解 + **曲线图/构型图**
4. 对照题给数据（拟合优度/残差）
5. 极限与量纲检查一句（体现严谨）

**一句话：** 单位统一、量级自查、极限行为对、参数必溯源、有实测必拟合出图。
