# 图表规范与出图清单（plot-spec）

> 对得上：任何阶段的图。图是评委第二眼看到的一切：初筛看摘要，粗评审看图表。图垃圾 = 表达清晰度直接掉档。
> 硬闸：**所有图由真实数据绘制**（`结果/q*/figs/`），禁止手工编数据画图冒充结果图。

## 一、统一风格（全文一致）

| 项 | 规范 |
|----|------|
| 字体 | 中文（宋体/黑体由 matplotlib 配置）、西文 Times New Roman；图内文字不小于正文 |
| 尺寸 | 单栏 8~10 cm、双栏 16~18 cm；dpi ≥ 300（PDF 插入用矢量优先：savefig 为 pdf/svg 再转） |
| 配色 | 一个主色 + 1~2 个辅助色；全文统一（蓝橙对比可）；禁止默认彩虹色堆砌 |
| 坐标轴 | 有轴标签（物理量 + 单位）、刻度合理、必要图例；网格浅灰 |
| 编号 | 图 1/图 2…；表 1/表 2…；图题在图下、表题在表上；**正文中必须被引用**（「如图 3 所示」） |
| 中文字体 | `plt.rcParams["font.sans-serif"]=["SimHei","Songti SC","Noto Sans CJK SC"]`；负号 `axes.unicode_minus=False` |

## 二、每题出图清单（按问挑 1~2 张，全文 8~15 张为宜）

| 阶段/问型 | 出什么图 |
|-----------|----------|
| 数据摸底 | 缺失率条形图、分布直方图、时序总览、相关热力图（挑 1~2 张进论文「数据预处理」） |
| 评价类 | 排名条形图（得分降序）、雷达图（前 3 名多维对比）、权重饼图/条形 |
| 预测类 | 历史 + 拟合 + 预测（置信区间带）一张合一、误差曲线 |
| 优化类 | 方案结构图（甘特图/排班表热力图）、目标值收敛曲线（启发式）、帕累托前沿（多目标） |
| 微分方程 | 状态变量时序曲线、相图、多情景曲线族 |
| 图论类 | 网络图/路线图（节点标号、路径高亮）、选址点位图 |
| 仿真 | 收敛曲线（重复次数 vs 均值）、结果分布直方图 |
| 机器学习 | ROC/AUC、特征重要性条形图、混淆矩阵热力图 |
| 检验 | 龙卷风图（灵敏度）、残差图 |
| 全卷 | 技术路线流程图（问题分析节，必出） |

## 三、表格规范

- 三线表（顶线/栏目线/底线），无竖线；对齐：文字左、数字右
- 表头带单位；数据来自 `结果/q*`，**与正文数字一致**
- 大表（>10 行）可放附录，正文给摘要版
- 表中数字统一有效位（2~4 位有效数字，全文一致）

- 双轴慎用（易误读）；需要时明确标注左右轴

## 五、常见坑

- 图没有轴标签/单位
- 图题与内容不符（图题说预测，图里只有拟合）
- 彩虹色堆砌、密密麻麻的网格线
- 坐标轴数字不统一格式（科学计数法混原值）
- 图没有被正文引用（孤儿图）
- 用示意图冒充结果图（红线违规）
- 中文乱码（没配字体）

## 六、论文里写什么

每张图在正文有 1~2 句「这张图说明什么」（不是复述图题，而是**从图里读出的结论**）。

**一句话：** 真数据出图、统一风格、轴标有单位、图必有题且正文引用、每图配一句读图结论。
