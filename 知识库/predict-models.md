# 预测建模（predict-models）

> 对得上：预测未来值/趋势/需求/占比、时间序列。
> 主线：序列形态判断 → 平稳性 → 选模型 → 验证（回测）→ 区间。

## 一、先分类再选法

| 数据形态 | 默认首选（起点，非铁律） | 备选 |
|----------|------|------|
| 时间序列、历史点 <10 | **灰色 GM(1,1)** | 指数平滑、二次拟合 |
| 时间序列、≥20 期 | **ARIMA**（先平稳性检验） | Holt-Winters（有季节性）、Prophet |
| 有季节周期 | SARIMA / Holt-Winters 季节项 | STL 分解 + 分项预测 |
| 截面多变量、要解释「哪些因素影响」 | **多元回归**（OLS + 显著性） | 岭回归（共线重）、分位数回归 |
| 非线性关系明显 | 多项式/SVM/神经网络 | 随机森林回归 |
| 多变量互相关且都要预测 | VAR | 组合模型 |
| 逻辑型（是否/发生概率） | Logistic 回归 | 决策树 |
| population/增长类 | Logistic 阻滞增长 | Malthus（对比基线）、Leslie 矩阵（年龄结构） |

**点数阈值（<10 GM、≥20 ARIMA）只是缺信息时的默认起点**。定模型前先过检查单：

```
□ 预测步长/样本长度比多少？（样本 20 期预测 50 期 = 外推远超支撑）
□ 采样频率与观测窗口？（月度 24 期 ≠ 季节信息充分；季节模型需 ≥2~3 个完整周期）
□ 有没有结构突变（政策/疫情断点）？→ 分段建模或加虚拟变量
□ 非平稳来自趋势、季节还是制度变化？→ 决定差分/季节差分/分段
□ 有外生变量可用吗？→ ARIMAX/回归
□ 间歇/稀疏需求（大量零值）？→ Croston 类方法，不用 ARIMA
□ 多层级序列（总量+分量）？→ 自上而下/自下而上调和
```

## 二、时间序列主线（ARIMA 路径）

```
1. 画时序图（趋势/季节/异方差一眼判断）
2. 平稳性：ADF 检验（p<0.05 平稳）→ 不平稳则差分（d=1,2）+ 取对数去异方差
3. 定阶：ACF/PACF 截尾或 auto_arima（pmdarima）/ AIC 最小
4. 拟合 statsmodels.tsa.arima.model.ARIMA
5. 残差白噪声检验（Ljung-Box）——没过 = 模型没提取完信息，调阶数
6. 预测 + 置信区间（forecast 返回的 conf_int 画带状区间图）
7. 回测：rolling-origin 多起点滚动回测（默认留出最后 20% 起步）报误差
```

**GM(1,1) 短要点**：累加生成 → 1 阶灰微分方程 → 最小二乘估 a,b → 后验差比 C、小误差概率 P 检验精度等级（P>0.95 & C<0.35 = 好）。用前先过**级比检验** λ^(0)(k) ∈ (e^{-2/(n+1)}, e^{2/(n+1)})，数据不满足就不硬用；**必须**与 naive/线性趋势/指数平滑基线对比，不优于基线就不用，并声明适用性。

## 三、回归主线

```
1. 散点/相关矩阵初判线性关系
2. 共线性：VIF > 10 剔除或岭回归
3. OLS → 系数表（t 值、p 值、R²、调整 R²）
4. 残差诊断：正态(Q-Q 图)、异方差(BP 检验→稳健标准误)、自相关(DW)
5. 显著变量 → 解释含义（经济/业务解释一句）→ 用回归方程做预测
```

非线性形态：先看散点选变换（对数/幂/多项式），**禁止**上来就高阶多项式拟合全数据（外推爆炸）。

## 四、机器学习预测（样本多时）

随机森林/XGBoost 回归：特征工程（`data-cleaning.md` §五）→ 时序数据必须用**前向滚动验证**（walk-forward），禁止随机 shuffle 划分 → 特征重要性出图 → 与 OLS/ARIMA 对照。

## 五、组合预测（加分项，评委认）

- 线性组合：f = w1·f_ARIMA + w2·f_回归（权重按误差倒数或最小二乘定）
- 对比表：单模型误差 vs 组合误差；组合更优才写组合
- 或「多方法互相印证」：三个模型预测带都落在同一区间 = 稳健证据

## 六、验证与误差（预测类必须给）

| 指标 | 用途 |
|------|------|
| MAPE / RMSE / MAE | 报回测误差（默认留出最后 20% 起步；更稳用 rolling-origin 多起点滚动回测） |
| R² | 拟合优度（回归） |
| 区间宽度 + 覆盖率 | 预测不确定性（95% CI；回测区间覆盖率能算就算，`uncertainty-and-identifiability.md`） |
| 基线对比 | naive（上期值）基线必须跑，主模型必须显著优于 naive 才算模型有效 |

## 七、常见坑（假点）

- 不做平稳性/白噪声检验直接上 ARIMA → 结果站不住
- 拿截面数据当时间序列拟合趋势
- 只给点预测不给区间 → 「结果的正确性」存疑
- 外推远期（预测 10 年后）用高阶多项式 → 曲线上天
- 用 MAPE 当唯一指标且序列有零值（MAPE 爆炸）→ 换 MAE/RMSE

## 八、论文里写什么

1. 序列图 + 形态判断（趋势/季节/平稳性）
2. 检验表（ADF p 值、Ljung-Box p 值）
3. 模型与阶数（或 GM 参数 a,b）、拟合曲线图（R²）
4. **预测值表 + 带区间的预测曲线图**（数字进 `结果/q*/summary`）
5. 回测误差表 + 基线对比一句

**一句话：** 形态先看、ADF/Ljung-Box 必检、短序列 GM 长序列 ARIMA、预测必带区间、误差必对 naive 基线。
