# 结果检验与稳健性（result-check）

> 对得上：任何要进论文的结果；题面点名「灵敏度/稳健性/可靠性」。
> 这是省奖与国奖的常见分水岭：没做检验的模型只算「跑通了」，不算「站住了」。
> 本篇是「独立验证证据菜单」与「检验参数纪律」的唯一出处；workflow/modeling-value 只引用不改写。

## 一、两级检验（先分清什么时候做什么）

| 级 | 时机 | 内容 |
|----|------|------|
| **单问最低验证** | 该问收口前，立刻做（轻量，不挡推进） | sanity 三连（量级/方向/边界，§四）+ 独立验证证据 ≥1 项（§三）+ 结果重算核对（目标值/口径） |
| **全文检验汇总** | Phase 4 成文前统一 | 跨情景灵敏度（§二）、稳健性（子样本/扰动/情景重跑）、基线对比、模型对比、汇总图表与检验节成文 |

「立刻检验」与「最后统一补」由此分工：单问只做最低验证，全文检验不压到最后一小时。

## 二、灵敏度分析（范围按来源定，阈值不写死）

**参数扰动范围从哪来（按优先级）：**

| 优先级 | 来源 | 做法 |
|--------|------|------|
| 1 | 题面/附件给的区间 | 在区间内取点（含端点与中点） |
| 2 | 参数估计的置信区间/标准误 | 在 CI 内扰动（如 ±1~2 个标准误） |
| 3 | 物理常识范围 | 量纲与量级约束内取点；跨数量级参数按**对数均匀**取点（±10% 没有意义） |
| 4 | 无任何信息 | 默认 ±5%、±10% 两档起步，并注明「默认扰动幅度」 |

**做法：**

```
1. 锁定关键参数：从模型结构挑（β、权重 w、单位成本 c、需求 d）2~4 个
2. 扰动：按上表范围取 2~3 档，每次单独动一个（其余不变）
3. 记录：结果变化率；参数交互明显时上全局方法（Sobol/Morris，见 uncertainty-and-identifiability.md）
4. 展示：龙卷风图（各参数对结果的敏感度排序）或多曲线族
5. 结论：敏感/稳健的判据由**问题容忍度**决定，不写死 5%/30%
   ——「结果变化 <5%」只说明目标量变化小；决策是否稳健还要看最优方案有没有翻转
```

**优化问题加查一条**：目标值几乎不变但**最优方案完全更换** = 决策不稳健（临界参数在跳变）；目标值与方案稳定性分开报。

**为什么这些参数重要**：题面强调的、拟合时标准误大的、评委容易质疑的（主观权重、假设的系数）。

## 三、独立验证证据（菜单制，替代「必须再跑一个模型」）

**每问 ≥1 项，从菜单选最省力且真正独立的那种**（「独立」= 不与主模型共享同一错误源）：

| 证据类型 | 适用 | 一句话做法 |
|----------|------|-----------|
| 第二模型 | 同一问有现成第二路线 | 主 ARIMA vs 指数平滑；主 MIP vs 贪心下界 |
| 解析特例 | 有可手算的小算例 | 缩到 2~3 个对象的规模，解析解 vs 数值解 |
| 守恒/极限关系 | 有守恒量或边界行为 | 质量守恒、能量守恒核对；参数 →0/∞ 时解趋于已知形态 |
| KKT/对偶 | 凸优化/LP | 对偶变量（影子价格）解释合理性；KKT 条件残差 |
| 约束残差 | 任何优化/方程解 | 逐条约束代回：违反量 ≤ 容差 |
| naive 基线 | 预测/评价/优化都可 | 均值/上期值/线性趋势/贪心；主模型必须优于基线，差值 = 模型增益 |
| 小规模穷举 | 离散决策、规模小时 | 穷举全部方案验证启发式/求解器 |
| 留出验证/回测 | 预测、ML | 滚动回测（rolling-origin），报告误差指标 |
| 外部数据对照 | 有公开统计数据 | 结果与公开统计口径对照（量级/趋势） |
| 数值收敛阶 | 数值解（PDE/积分/ODE） | 网格/步长减半，看解的收敛阶是否符合理论 |

**关键纪律——「两模型接近 ≠ 稳健」**：

- 第二模型可能共享相同错误数据、相同错误假设、同源系统性偏差
- 数值接近 → 正文只能写「两种方法在指标 X 上结果接近」，**禁止**自动升级为「模型稳健」
- 升级为「稳健」需要独立证据：不同数据来源、不同假设结构、或扰动/子样本重跑结论不变
- 差异大 → 查原因（口径/假设不同），正文如实交代差异来源，**不硬说一致**

## 四、合理性 sanity 三连（单问收口前最后一道闸）

- [ ] 量级：结果与题面/常识同量级？（结果值除以题面已知量，差 10 倍以上必须查）
- [ ] 方向：价格升需求降？成本增利润减？（反常识 = 有 bug）
- [ ] 边界：最优解顶到某约束边界（0 或上限）？顶死的要检查约束有没有写错
- [ ] 极端情形：参数取 0/∞ 时行为合理？
- [ ] 复现：换台机器重跑代码，数字能复现吗（固定种子、随机性来源已控）？

## 五、没做别写（反造假闸）

| 论文句 | 前提 |
|--------|------|
| 「模型具有较好的稳健性」 | 真做了扰动/子样本重跑（且方案不翻转） |
| 「灵敏度分析表明…」 | 真有灵敏度数字/图 |
| 「预测误差较小」 | 真算了误差指标 |
| 「两模型结果一致」 | 真跑了独立验证，且只说「指标 X 上接近」 |

没做 → 只写已做到的（「在假设 X 下求得最优方案」）。

## 六、论文里写什么（检验节模板）

1. 检验设计一句（「对参数 β、w 在其置信区间内取三点扰动」）
2. 灵敏度图（龙卷风图或折线族）
3. 独立验证证据对照表（主模型 vs 第二路/基线/解析特例）
4. 误差表 + 方案稳定性结论（优化的题必写）
5. 结论一句（敏感项交代 + 稳健性判断 + 对假设的影响）

**一句话：** 单问最低验证立刻做、全文检验 Phase 4 汇总；扰动范围按来源定、判据按容忍度定；独立证据从菜单挑、两模型接近只写「指标接近」不写「稳健」；没做的检验一个字不写。
