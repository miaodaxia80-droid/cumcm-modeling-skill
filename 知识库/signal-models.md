# 信号处理建模（signal-models）

> 对得上：音频/振动/传感器序列、频谱分析、周期检测、滤波去噪、故障特征提取。
> 主线：采样检查 → 预处理 → 变换（频域/时频）→ 特征 → 建模/分类。
> 与 `data-cleaning.md`（通用清洗）、`stat-models.md`（检验）、`ml-models.md`（分类下游）配合。

## 一、采样与预处理（先查数据资格）

| 检查 | 要点 |
|------|------|
| 采样定理 | 信号最高频率必须 < 采样率/2；采样率不足 → 高频混叠，后面全白算；采样率不明时从数据标注/题面找 |
| 去趋势/去均值 | FFT 前去均值（否则 0 频泄漏）；有趋势先去趋势（否则低频假峰） |
| 窗函数 | 截断导致频谱泄漏；加 Hann/Hamming 窗（对比加窗前后谱） |
| 缺失/断点 | 均匀采样是 FFT 前提；缺口先插值或分段处理（`data-cleaning.md`） |

## 二、频域分析

```python
import numpy as np
x = ...                          # 等间隔采样序列
n = len(x)
xw = np.hanning(n) * (x - x.mean())          # 去均值 + 加窗
X = np.fft.rfft(xw)
freq = np.fft.rfftfreq(n, d=1/fs)            # fs = 采样率
amp = np.abs(X) / (n/2) * 2                  # 幅值谱（单边）
peak = freq[np.argmax(amp[1:]) + 1]          # 主频
```

| 任务 | 工具 |
|------|------|
| 频谱/功率谱 | `rfft` 幅值谱；功率谱 `scipy.signal.welch`（分段平均更平滑） |
| 主频/谐波识别 | 谱峰 + 题面机理对照（转频、啮合频率、电网 50 Hz…） |
| 频带能量分布 | 分频带积分（低/中/高频段占比当特征） |
| 滤波去噪 | `scipy.signal.butter` + `filtfilt`（零相位）；带通保留目标频段；**注意 filtfilt 需要序列足够长于滤波器阶数** |

## 三、周期检测（三条路互验）

1. **FFT 谱峰**：显著峰位 → 周期 = 1/f；峰要过显著性（对比背景谱水平，防噪声峰）
2. **自相关**：`np.correlate` / `statsmodels.acf`——第一个显著峰的滞后 = 周期；对非正弦周期信号比 FFT 稳
3. **STL 分解**：`statsmodels.tsa.seasonal.STL`——季节项直接给出周期形态（`predict-models.md` 联动）
三条路周期一致 → 结论稳；不一致 → 查混叠/趋势/非平稳。

## 四、时频分析（频率随时间变化时）

| 方法 | 适用 | 工具 |
|------|------|------|
| STFT 频谱图 | 频率缓变 | `scipy.signal.stft`；窗长权衡：短窗时间准、长窗频率准 |
| 小波变换 | 多尺度、瞬态突变 | `pywt.cwt`（连续）/ `pywt.wavedec`（离散去噪：小波阈值去噪 wdenoise 思路） |
| 包络分析 | 轴承/调制类故障 | Hilbert 变换取包络 → 对包络再做谱分析 |

## 五、特征提取（喂分类/聚类/回归）

| 域 | 特征 |
|----|------|
| 时域 | 均值、方差、峰峰值、RMS、峰值因子（crest）、峭度（冲击敏感）、偏度 |
| 频域 | 主频、频带能量占比、谱重心、特征频率处幅值 |
| 时频 | 小波包能量熵、STFT 图（可当 CNN 输入，`ml-models.md`） |

**纪律**：特征必须能对应物理含义（评委问「这个特征为什么区分故障」要答得上）；特征数 vs 样本数过 `modeling-core.md` §三可识别性快检。

## 六、验证（信号题的独立证据）

- **合成信号自检**：自己生成已知频率/幅值的正弦+噪声 → 整条流水线跑一遍 → 能否恢复真值（方法可信的证据，先于真实数据）
- 滤波对照：滤波前后信号对比图 + 有效信息是否保留（过度滤波把特征滤没了）
- 参数敏感性：窗长/小波基/滤波截止频率扰动 → 特征与结论是否稳定（`result-check.md` §二范围纪律）
- 分类下游：交叉验证指标 + 混淆矩阵（`ml-models.md`），禁止随机打乱后按样本划分高度相关段（分段/按受试者划分）

## 七、常见坑（假点）

- 采样率不够还硬做频谱 → 混叠频率冒充真实频率
- 不去均值/不加窗直接 FFT → 0 频大峰和泄漏淹没真实峰
- 谱上随便指一个峰当「故障频率」→ 没有机理对照、没有显著性
- 中心差分/朴素滤波引入相位滞后 → 时间对齐错
- 特征几十个、样本几十条 → 过拟合，可识别性没过
- 对强非平稳信号只看全局 FFT → 瞬态信息全丢（该上时频）

## 八、论文里写什么

1. 采样信息一段（采样率、时长、采样定理满足性）
2. 预处理流程（去趋势、加窗、滤波参数及理由）
3. **频谱/时频图**（标注显著峰与对应物理频率；中文坐标轴规范 `plot-spec.md`）
4. 周期/特征频率表（三条路互验结果）
5. 特征表 + 下游模型指标（如分类）+ 合成信号自检一句

**一句话：** 采样资格先查、去均值加窗再变换、周期三路互验、合成信号先自检、特征带物理解释、时变信号上时频。
