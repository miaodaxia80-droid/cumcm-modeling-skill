# 随机与仿真（sim-models）

> 对得上：随机到达、排队、概率事件、仿真验证、蒙特卡洛。
> 主线：随机机制建模 → 大量重复 → 统计收敛 → 区间与分布。

## 一、纪律总闸（仿真题最容易造假）

1. **重复次数：按精度序贯停止**——目标估计量的 95% CI 半宽 < 需要的精度即停（精度由题面要求/决策容忍度定）。无信息时默认 10 000 次起步、关键结论 100 000 次；**单次仿真下结论 = 违规**。稀有事件（p~10⁻⁴ 级）按「事件发生数 ≥ 数百」反推所需次数，固定 1 万次远远不够
2. **固定种子**：`rng = np.random.default_rng(42)`；种子进代码，保证可复现
3. **收敛证据**：重复次数 vs 估计值曲线（估计值稳定后停机）；或给均值 ± 95% 置信区间
4. **对照**：仿真结果与解析解/理论值对照（有解析解时），或与题面给的数据分布对照

## 二、蒙特卡洛模板

```python
import numpy as np
rng = np.random.default_rng(42)
N_max, batch, tol = 200_000, 5_000, 0.01   # 上限/每批/目标CI半宽（序贯停止）
results = []
for _ in range(N_max // batch):
    batch_res = [...]           # 按概率机制抽样 → 该批各次结果
    results.extend(batch_res)
    arr = np.asarray(results)
    half = 1.96 * arr.std(ddof=1) / np.sqrt(len(arr))
    if half < tol:              # CI 半宽达标 → 停；达不到且到 N_max → 报告精度上限
        break
mu = arr.mean(); ci = mu + half * np.array([-1, 1])
```

常见用法：概率估计（成功率）、积分/期望、随机系统（库存/备件）、置信区间。

## 三、排队论

| 模型 | 公式要点 |
|------|----------|
| M/M/1 | ρ=λ/μ<1；L=ρ/(1-ρ)；W=1/(μ-λ) |
| M/M/c | ρ=λ/(cμ)<1；用 Erlang C 公式算等待概率 |
| M/M/c/K | 有限队长；溢出概率 |
| 到达不服从泊松 | 经验分布抽样仿真（实测到达间隔分布） |

落地：算队长/等待时间/利用率 → 资源配置建议（开几个窗口/通道，服务水平目标反推 c）。

## 四、元胞自动机 / 离散事件仿真

| 类型 | 用法 |
|------|------|
| 元胞自动机 | 空间格点 + 局部规则演化（火势蔓延/交通流/生态）；规则要能对应机理 |
| 离散事件仿真 | 到达/服务事件队列（用 simpy 或自写事件循环）；输出队列长度时序、利用率 |
| 马尔可夫链 | 状态转移矩阵 → 平稳分布（求特征向量）；长期概率问题 |

## 五、验证仿真可信（result-check 的仿真版）

- 解析特例对照：能求解析解的小算例（M/M/1）上仿真 vs 解析一致 → 仿真器可信
- 分布对比：仿真输出分布 vs 实测分布（KS 检验或直方图叠加）
- 敏感性：关键参数按范围扰动重跑（范围纪律认 `result-check.md` §二）→ 结论是否翻盘

## 六、常见坑（假点）

- 单次仿真下结论
- 没固定种子（结果不可复现）
- 到达过程拍脑袋（应从数据估 λ 或拟合间隔分布）
- 忽略初始瞬态（warm-up 期数据要丢弃）
- 用仿真验证了「自己造的规则」却没对照真实数据

## 七、论文里写什么

1. 随机机制假设（到达/服务/概率分布从哪来）
2. 仿真方案（重复次数、种子、收敛证据）
3. **结果表（均值 ± CI）+ 分布图/收敛曲线**
4. 解析对照（有解析解的特例一致）
5. 情景对比（不同参数/策略的仿真结果族）

**一句话：** 种子固定、按精度序贯停止给收敛证据、解析特例对照；单次仿真=违规，固定次数不看精度=盲跑。
