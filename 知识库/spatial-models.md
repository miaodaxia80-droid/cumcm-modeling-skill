# 空间与地理建模（spatial-models）

> 对得上：经纬度/坐标数据、选址覆盖、空间插值（气象/污染面）、区域聚集、空间分布格局。
> 主线：坐标与投影 → 距离/邻接 → 插值或自相关分析 → 空间模型 → 地图出图。
> 与 `graph-models.md`（网络类）、`plot-spec.md`（地图类图）、`stat-models.md`（回归）配合。

## 一、坐标与距离（先算对距离再谈空间）

| 任务 | 工具 | 要点 |
|------|------|------|
| 经纬度球面距离 | haversine 公式 / `geopy` | **禁止**直接对经纬度做欧氏距离（纬度 1°≈111km，经度随纬度变 → 距离错数倍） |
| 投影到平面 | `pyproj`（选合适 UTM 带）/ 等积投影 | 覆盖范围小（城市内）投影后误差可忽略；大范围必须投影 |
| 路网距离 | `OSMnx` / 地图 API | 排2024 配送/可达性题用路网距离，欧氏距离只是下界 |
| 邻接定义 | 网格 4/8 邻域、行政区邻接表、K 近邻、距离阈值 | 空间权重矩阵 W 的定义要写进论文（结果依赖它） |

## 二、空间插值（点观测 → 面分布）

| 方法 | 适用 | 要点 |
|------|------|------|
| 反距离加权 IDW | 快速、无分布假设 | 幂参数 p（默认 2）做敏感性；不能外推出数据范围 |
| **克里金 Kriging** | 有半变异结构、要插值方差 | `pykrige`；半变异函数模型（球状/指数）拟合要报告；给插值方差图（不确定性，`uncertainty-and-identifiability.md`） |
| 样条/趋势面 | 平滑趋势 | 防过拟合，交叉验证选光滑参数 |
| 验证 | 留一交叉验证（LOOCV） | 报 RMSE/MAE 对比不同插值方法，选优有据 |

## 三、空间自相关（「分布是不是聚集的」）

```
全局 Moran's I：相邻区域取值相似（正=聚集，0=随机，负=分散）
  → 显著性用置换检验（999 次重排，随机空间不换）
局部 Moran's I（LISA）：哪里是高-高、低-低、高-低异常点 → 出 LISA 聚集图
Geary's C / Getis-Ord Gi*：备选；热点分析用 Gi*
```

**纪律**：Moran's I 依赖权重矩阵 W——至少两种 W（邻接/K近邻）下结论都成立才算稳；样本 <30 个区域时解释要保守。

## 四、空间回归（有空间数据的回归）

| 问题 | 模型 |
|------|------|
| OLS 残差有空间自相关（Moran's I on residuals 显著） | OLS 不合格 → 空间滞后模型 SLM（y 依赖邻居 y）或空间误差模型 SEM |
| 选 SLM 还是 SEM | LM-lag/LM-error 检验（`spreg`/`pysal`）；或 AIC 对比 |
| 解释变量空间溢出 | 空间杜宾 SDM |

**要点**：空间数据样本常少、区域异质性强——报告稳健标准误；先把「空间无关」当零假设检验过，显著才上空间模型，不显著用普通回归即可。

## 五、空间优化/覆盖（与 graph/op 联动）

| 问题 | 模型 |
|------|------|
| 选址覆盖（消防站/充电桩） | 集合覆盖（覆盖全部需求点最少设施）/ 最大覆盖（给定 p 个设施覆盖最多需求）——MIP 实现（`op-models.md`） |
| P-中值（设施选点+分配） | 最小化加权距离和；`pymoo`/自写或 MIP |
| 距离衰减需求 | Huff 模型/引力模型（需求 = 规模/距离^β），β 用数据拟合或文献值并做敏感性 |

**距离矩阵纪律**：程序生成 + 落盘 `数据/dist_matrix.csv` 可复算（`graph-models.md` 同款纪律）；欧氏/路网距离在正文注明口径。

## 六、出图（空间题的图就是说服力）

- 底图地图（区域填色 choropleth / 散点插值热力图）+ 指北针/比例尺/图例
- LISA 聚集图、插值方差图（不确定性可视化）
- 中文标注字体配置（`solver-toolkit.md` §三）；出图规范认 `plot-spec.md`

## 七、常见坑（假点）

- 经纬度直接算欧氏距离 / 直接当平面坐标回归 → 系数和距离全错
- 插值外推到数据覆盖范围之外 → 克里金/IDW 在边界外无意义
- 只用一种空间权重就下聚集结论 → W 换了结论就翻的必须交代
- OLS 残差空间自相关没检验 → 系数标准误失真
- 空间样本几十个硬上高维空间回归 → 过拟合（`modeling-core.md` §三）
- 覆盖模型忽略需求点权重差异（人多的区一个样）→ 方案脱离实际

## 八、论文里写什么

1. 数据空间信息一段（坐标系、范围、分辨率/数量）
2. 距离/邻接定义（权重矩阵 W 怎么建的）
3. 插值方法 + LOOCV 误差对比表 + **插值热力图**
4. 空间自相关结果（Moran's I 值 + 置换检验 p 值 + LISA 图，如适用）
5. 空间优化方案图（选址/覆盖结果叠地图）

**一句话：** 投影/球面距离先算对、插值必过留一交叉验证、聚集结论要换权重矩阵复核、残差空间相关检验后再谈空间回归、方案图叠地图说话。
