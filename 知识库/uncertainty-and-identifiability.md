# 不确定性与可识别性（uncertainty-and-identifiability）

> 对得上：要给区间/置信度/误差棒、参数校准、稳健结论、「结果有多可信」。
> 这是建模深度的分水岭：点估计人人会给，不确定性量化才区分「跑通了」和「站住了」。
> 灵敏度扰动范围、独立验证菜单认 `result-check.md`；本篇是理论深化出处。

## 一、三类不确定性（先分类再选工具）

| 类 | 是什么 | 工具 |
|----|--------|------|
| **参数不确定性** | 拟合/估计的参数本身有误差 | 标准误、置信区间、bootstrap、profile likelihood |
| **观测不确定性** | 数据带噪声/测量误差 | 误差传播、加权拟合、状态估计（`control-models.md`） |
| **结构不确定性** | 模型形式本身就可能不对 | 多模型对比、模型平均、交叉验证、`result-check.md` §三独立证据 |

## 二、参数置信区间（四条路，按代价排）

| 方法 | 适用 | 做法 |
|------|------|------|
| 解析标准误 | 线性回归、MLE 渐近 | `statsmodels` 系数表直接给 CI；报告时写「95% CI [a, b]」 |
| **bootstrap**（通用兜底） | 几乎任何估计量 | 重抽 B=1000~5000 次 → 每次重估参数 → 取 2.5%/97.5% 分位；时序数据用**块 bootstrap**（block length ~√n），禁止对时序逐点重抽 |
| profile likelihood | 非线性拟合、参数相关性存疑 | 固定参数 θ_i 在网格上重拟其余参数 → likelihood 下降 1.92（95%）的区间 |
| Monte Carlo 传播 | 参数有已知分布、要输出量分布 | 参数按分布抽样 N 次 → 过模型 → 输出量的分位区间 |

**纪律**：论文里报参数估计必须带 CI（或标准误）；没算就不写「精确控制」类结论。

## 三、误差传播（输入误差 → 输出误差）

```
解析（一阶）：若 y = f(x)，Δy ≈ Σ|∂f/∂x_i|·Δx_i（独立）或含协方差项
数值：Monte Carlo——输入按其不确定性分布抽样，跑模型，看输出的 spread
检查：哪个输入贡献最大 → 它就是要重点交代假设和做灵敏度的参数（联动 result-check §二）
```

## 四、全局灵敏度（参数交互明显时）

| 方法 | 适用 | 要点 |
|------|------|------|
| 局部（弹性/导数） | 单因素、近似线性 | 弹性 = (∂y/∂x)·(x/y)，跨量纲可比 |
| **Morris 筛选** | 参数多（>10）、先筛重要的 | elementary effects 均值（总影响）与标准差（非线性/交互）排序 |
| **Sobol 指数** | 参数 2~10 个、要定量分解 | 一阶指数 = 单独贡献；总阶指数 = 含交互贡献；S1+ST≈0 的参数可固定 |
| 龙卷风图 | 汇报 | 各参数单因素扰动的敏感度排序一张图（`plot-spec.md`） |

**判据纪律**：敏感/稳健的结论由问题容忍度决定；优化的题目标值稳定与方案稳定分开报（`result-check.md` §二）。

## 五、可识别性诊断（`modeling-core.md` §三的深化）

```
1. 结构性不可识别：不同参数组合给出完全相同的拟合 → 数据无解，必须改参数化或加先验
   检查：沿参数方向走线，likelihood 是否完全不变（平坦谷）
2. 实用性不可识别：CI 覆盖多个数量级 → 名义可估实际不可用
   检查：profile likelihood / bootstrap CI 宽度 vs 参数的自然范围
3. 数据含量：有效样本量（考虑自相关后）vs 参数数；残差自相关 → 拟合置信区间偏乐观
处置：减参数 / 参数重构（组合量）/ 加正则（numerical-models.md）/ 固定来源可靠的参数并声明
```

## 六、预测区间与覆盖率

- 点预测必须配区间：模型内在误差（残差）+ 参数误差，两者都要进（很多论文只算前者 → 区间偏窄）
- **覆盖率回测**：回测期里真实值落入 95% 区间的比例应接近 95%；明显偏低 = 区间低估不确定性，正文如实报并调宽
- 结构不确定性 → 多模型预测区间叠加（模型平均）或分模型分别给带

## 七、鲁棒决策（结论要经得起假设变化）

| 做法 | 一句话 |
|------|--------|
| 情景分析 | 题面/常识给的离散情景各跑一版，报结论是否翻转 |
| 权重/参数可行域 | 不确定参数当作区间 → 区间内 Monte Carlo → 排名/方案稳定性（评价类 top-k 稳定概率） |
| 最坏情况检查 | 鲁棒优化视角：结论在最不利参数取值下还成立吗（`op-models.md` §六b） |
| 决策稳定性 | 优化题必查：目标值几乎不变但最优方案翻转 → 结论措辞降级为「两方案相当」 |

## 八、常见坑（假点）

- 只报点估计不给任何区间 → 「结果正确性」存疑
- bootstrap 对时序逐点重抽 → 破坏自相关，CI 偏窄
- 拟合 R² 高就宣称参数可靠 → R² 管的是拟合不是参数精度（看参数 CI）
- 「模型 A 与 B 结果一致」当稳健证据 → 同源风险（`result-check.md` §三纪律）
- 灵敏度只做单因素、参数交互主导时下「稳健」结论
- 预测区间只含残差不含参数不确定性 → 覆盖率回测露馅

## 九、论文里写什么

1. 参数估计表（估计值 ± 标准误或 95% CI + 估计方法）
2. 不确定性来源一段（参数/观测/结构三类各一句）
3. 全局灵敏度图（Sobol/Morris/龙卷风，按参数量选）
4. 预测带区间图 + 覆盖率一句（预测类）
5. 稳健性结论（情景/可行域/决策稳定性；措辞按 `result-check.md` §五）

**一句话：** 三类不确定性先分类；参数必带 CI（bootstrap 兜底）；传播看谁贡献大；参数多上 Sobol/Morris；区间要过覆盖率回测；结论只写决策稳定支撑到的那一步。
