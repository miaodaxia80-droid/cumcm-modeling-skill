# 打穿短表（索引）

> 拆题先 `modeling-core.md` 形式化（问题五分类 + 最小模型说明表），再看本表选模块；对得上再打开「见 xxx.md」看细节（文件不长可整篇开，超长篇可先开点名节，不够就继续开）。禁止每题通读整库。进/补本表只认磁盘 `rules/iter-gain.md`（只增强、不限制）。改本表前必须先读该文件现稿，禁止用会话旧副本。
> **本表 ≠ 本题做法上限。** 打完开场枪立刻回 `contest-workflow` 主路径：拆题落进度 → 一问闭环真出数。表上没有的打法照样用。检验不是只测灵敏度一项。

| 认什么 | 打哪 | 出什么算成 | 假点 |
|--------|------|------------|------|
| 任何题、任何问开算前 | modeling-core 形式化：问题五分类（描述/预测/解释/控制/决策）+ 数据三型 + 关系三型 → 最小模型说明表；再回本表选模块。见 `modeling-core.md` | 每问能答「这问是预测还是决策」+ 自由度撑得起参数 | 按问句关键词直接套模型（算法分诊≠建模）；观测数据写因果结论；复杂模型没跑基线 |
| PDE 有限体积 | 表面半体积节点权重必须显式积分推导；守恒恒等式可能对成对出错的体积权重和通量内部自洽，必须再配解析特例或制造解对照。见 `numerical-models.md` §一 | 守恒检查 + 解析/制造解 + 网格收敛三类证据相互独立 | 守恒比为 1 就认为边界离散必然正确 |
| 移动边界/动网格 | 先明确原方程是欧拉导数还是物质导数，再从变量定义推导。若 u(x,t)=φ(xR(t),t) 且原式为固定 r 下 φ_t=Lφ，则 u_t=L_xu/R²+(xṘ/R)u_x；不得凭记忆套符号。网格间距用无量纲 dx，Ṙ 必须来自同一 R(t) 插值的导数。见 `numerical-models.md` §五 | 链式法则手算对照 + 制造解 + 网格/时间步收敛 | 混用 dr/dx；R(t) 与Ṙ(t) 不相容；未定义参考坐标就直接套对流项 |
| 问句带「根据附件 X 确定」 | 先判定附件是输入、校准数据、验证数据还是判据本身；“根据附件”不等于“把附件最后一行当答案”。终止条件以显式题意、跨问依赖和有依据的物理/统计定义共同确定；不自动继承，也不自动丢弃前问判据。见 `modeling-core.md` §二 | 每个输入与判据都有题面或模型定义来源；数据终点与过程终点明确区分 | 将采样结束、平台或文件最后时刻无论证地当成事件终点 |
| 要区间/置信度/「结果多可信」/参数校准 | 参数必带 CI（bootstrap 兜底，时序用块自助）→ 误差传播找主导参数 → 参数多上 Sobol/Morris → 预测区间过覆盖率回测。见 `uncertainty-and-identifiability.md` | 参数表 ±CI + 区间图 + 覆盖率一句 | 时序逐点 bootstrap；区间只含残差不含参数误差；R² 高就称参数可靠 |

| 认什么 | 打哪 | 出什么算成 | 假点 |
|--------|------|------------|------|
| 官方竞赛附件 Excel：键列是合并单元格、类型值带尾随空格、表尾有注释行、价格给区间不给定值 | 键列 ffill + 全表 strip + to_numeric 过滤注释行 + merge 前列名冲突改名；区间价格取中点并做扰动灵敏度。见 `data-cleaning.md`「官方 Excel 三闸」「四b」 | 清洗集 0 缺失、可一键复跑、行数与官方口径对上 | 尾部「注：」行不是数据行；纯 dropna 静默砍掉合并单元格块（实测 87→54 条） |
| 收入=「销量上限内全价 + 超额滞销/半价」分段形式 | 超额变量 z≥max(0,Q−D) 负系数线性化（k=1 滞销 / k=0.5 半价）；上限施加在 (作物,季,年) 聚合产量；核算函数与模型同口径。见 `op-models.md` §3.1-3.2 | 逐年重算利润 = 求解器目标（精确一致） | min(Q,D) 用在逐地块项（同作物超额被重复按全价计，实测虚高 670 万）；忘写 z ≥ Q−D（变无限需求） |
| 「不能连续重茬」+ 地块季数不同 | 双季地块=相邻季（含跨年相邻）；**单季露地=相邻两年同作物即重茬**；2023 实际种植对 2024 第一季跨年重茬必须编码。见 `op-models.md` §3.3 | 求解后抽查：任一地块相邻季/相邻年不同作物 | 把单季地块当双季口径漏跨年重茬；按往年题经验套当年条款（2023C 的 1.5/0.5 倍扩产限制 2024C 不存在） |
| 同结构模型做约束放宽/收紧对比 | 先验「放宽单调性」：放宽后最优值必须 ≥ 收紧前；违反 = 求解未收敛伪影。见 `solver-toolkit.md` 报错表、`op-models.md` §3.4 | 单调性成立的结果才进表格 | timeLimit 到点报的 Optimal 当真最优（实测 120s 假收敛虚低 12%）；把未收敛变体写进灵敏度表 |
| 附件多张 Excel/CSV，列含义不明、字段名是代号 | 先做数据字典：逐列读样值判类型（数值/类别/时间/文本），登记到 进度.md；分布/缺失/量纲三连看 | 每列有类型与用途判断，缺失/异常列有处置决定 | 拿到附件直接套模型；字段名望文生义不改字典 |
| 问「从 N 个方案中选最优 / 排名」 | 权重来源判定（真实判断→AHP+CR；只有数据→熵权；都要→α 组合三档敏感性）→ 聚合按决策结构选（TOPSIS/模糊/灰色/ELECTRE）→ 排名稳定性。见 `eval-models.md` | 全方案完整排名表（含并列）+ 前后名差距可解释 + 权重扰动/秩逆转检验不翻盘 | Agent 编 AHP 判断矩阵；熵权当「指标重要性」；α=0.5 无依据；两法排名一致就写「稳健」（只能写「接近」） |
| 问「预测未来 T 期」 | 先看序列长度：<10 期用 GM(1,1)/指数平滑；≥20 期做平稳性→ARIMA；多变量→回归/组合预测。细节见 `predict-models.md` | 点预测 + 区间/误差指标（MAPE 等）+ 预测曲线图 | 不做平稳性检验直接上 ARIMA；用截面向量当时间序列拟合 |
| 问「最大利润/最优分配/排班/调度」 | 写清决策变量/目标/约束 → LP/MIP（pulp/gurobi）；规模大→启发式；多目标→ε约束/帕累托。细节见 `op-models.md` | 最优目标值 + 决策方案表 + 求解器状态 optimal 可溯源 | 约束漏掉隐含常识约束（非负、整数、人数上限）；模型不收敛硬说"求解完成" |
| 变化率、增长、传染、衰减、捕食 | 微分方程/差分方程建模 → 平衡点与稳定性分析 → 数值解（odeint/solve_ivp）+ 参数反演（最小二乘拟合真实数据）。细节见 `diff-models.md` | 方程组 + 稳定性结论 + 拟合曲线图（R²）+ 预测曲线 | 只有解析式没有数值解和图；参数全是拍脑袋没标注来源 |
| 路径/配送/选址/网络 | 图建模：节点边表→最短路 Dijkstra/最小生成树/最大流/设施选址（P-中值）。细节见 `graph-models.md` | 最优路径/选址方案 + 距离成本表 + 路线图 | 距离矩阵手算出错没程序生成；忽略了容量/时间窗约束 |
| 随机到达/排队/检验概率 | 排队论 M/M/c 或蒙特卡洛仿真（万次重复取均值+置信区间）。细节见 `sim-models.md` | 仿真结果 + 收敛性证据（重复次数→均值稳定）+ 分布图 | 单次仿真就下结论；随机数没固定种子不可复现 |
| 大样本带标签/要做分类回归 | EDA→特征→随机森林/XGBoost 基线→交叉验证→对比逻辑回归。细节见 `ml-models.md` | 交叉验证指标（AUC/准确率）+ 特征重要性 + 混淆矩阵 | 只报一次 train/test split 的成绩；拿测试集调参 |
| 显著性/差异比较/相关性 | 先看数据类型与分布→选检验（t/ANOVA/卡方/Spearman）→ 报统计量+p 值+效应量。细节见 `stat-models.md` | 检验表（统计量、p 值、结论）+ 可视化 | 正态性没查就用 t 检验；只报 p 值不报效应量 |
| 几何/受力/运动/光学 | 物理定律列方程→无量纲化→数值解或解析解→与题给条件对照。细节见 `phys-geo-models.md` | 方程 + 数值解曲线 + 单位量纲自洽检查 | 忽略量纲不统一直接套公式 |
| 题面要求「灵敏度/稳健性/不同情景」 | result-check 两级检验：单问最低验证（sanity+独立证据）立刻做；灵敏度参数范围按来源定（无信息默认 ±10% 起步）；优化题方案稳定性单列。见 `result-check.md` | 灵敏度图（龙卷风图/折线族）+ 方案稳定性结论进正文 | 正文写"进行了灵敏度分析"但全文没有灵敏度图和数字；目标值不变就称稳健但最优方案翻转 |
| 摘要写作 | 8 要素逐问：模型名+方法+数字。细节见 `abstract-writing.md` | 每问都有具体数字的摘要 | 「建立了模型，取得了良好效果」式零数字句 |
| 数据重复列/编码不一致/单位混用 | data-cleaning 的「单位与口径闸」：统一量纲、合并口径、记录变换规则。细节见 `data-cleaning.md` | 清洗后的数据集 + 变换记录 + 前后对比统计 | 直接拿原始表建模；清洗动作没记录导致不可复现 |
| 问「多个目标要同时兼顾」（效益 vs 成本） | 多目标：加权/ε约束/NSGA-II 帕累托前沿。细节见 `op-models.md` | 帕累托前沿图 + 推荐方案及理由 | 只给一个权重组合的解还称"最优" |
| 时间序列多变量互相影响 | VAR/灰色关联分析先行定关联，再选主变量。细节见 `predict-models.md` + `stat-models.md` | 关联度表 + 变量选择理由 + 预测结果 | 没有共线性检查就上多元回归 |
| 题面给了两组对照数据/新旧方法对比 | 基线对比闸：先用最笨的方法（均值/线性）做基线，再上 fancy 模型，差值才是模型增益。细节见 `result-check.md` | 基线 vs 主模型对比表 | 没有基线直接宣称模型效果好 |
