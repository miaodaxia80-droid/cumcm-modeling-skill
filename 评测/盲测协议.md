# 盲测评测协议（真实能力校准）

> 目的：文档自证不了「强大」。用公开旧题盲测校准本 skill 的真实做题能力；每个题型线至少过一题才可声称该线可靠。
> 当前校准状态：C 题线已过 2024C 首轮校准（13 卡点回写，见短表）；A/B 题线、博弈论未校准。
> 跑法：练习模式做完 → 按 §三十项打分 → 卡点/新打法按 `rules/iter-gain.md` 回写短表。

## 二、执行纪律

1. 盲测 = 只给题面与附件，不给任何思路提示；按 `contest-workflow` 全流程跑
2. 每题限时（练习模式建议单题 ≤ 4h 计算墙钟，不计写作全部时间）
3. 结果落标准任务根；结束跑 `scripts/verify_task.py`，FAIL 清零才算提交态

## 三、评分（不看「论文写得像不像」，只看）

| # | 项 | 判据 |
|---|----|------|
| 1 | 理解题目 | 拆题表与题面问句一一对应，无答非所问 |
| 2 | 模型回答题问 | 每问模型输出 = 题面要的输出形态（数值/排名/方案） |
| 3 | 变量与约束完整 | 常识约束清单全；无漏维状态空间 |
| 4 | 数值可复现 | 代码按 README 一键复跑数字一致；种子固定 |
| 5 | 无信息泄漏 | CV/回测划分正确；填补统计量不跨折 |
| 6 | 独立验证 | 每问 ≥1 项独立验证证据，非同源双模型凑数 |
| 7 | 不确定性量化 | 参数 CI / 预测区间 / 灵敏度范围按来源定 |
| 8 | 结论不超证据 | 无「稳健/精确」超写；两模型一致只写「接近」 |
| 9 | 论文与结果一致 | 摘要=正文=图=结果文件四处同源（verify_task 数字溯源过） |
| 10 | 合规 | 匿名、格式、提交包按 paper-format + package_submission 通过 |

## 四、通过标准与回写

- 单题 ≥ 8/10 且无造假类 FAIL = 该题通过；题型线连续两题通过 = 该线视为已校准
- 未过 → 差异归因到具体卡点 → 按 `iter-gain.md` 门槛+三问决定是否回写短表/模块
- 每轮盲测在本文件 §五 登记一行（日期、题号、得分、卡点指针），不写流水复盘
